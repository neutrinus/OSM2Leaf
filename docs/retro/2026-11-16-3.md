## The catch that matters: a set compared where a multiset was needed

H69's navigator found that `compare_live` keyed citations into a **dict**, so two
identical `(file,line,va,kind)` rows collapsed to one. Deleting one of two
identical rows — or adding a duplicate of a unique row — left the dict
unchanged, and the gate **exited 0**. That is silent citation loss inside the
very artifact M1.30 froze to protect against silent loss. The navigator built
the case on the committed snapshot *before* reviewing code; the fix
(`8bd307f`) added per-key `Counter`s and three selftest cases (**53 checks**).
The TL independently deleted one of seven `TODO.md 0x0041c7dc fn` rows and got
`CORPUS STALE: 1 new`, exit 1. Class: **integrity**, not evidence.

The same EXP also carried an unreproducible count — "44 identities / 188 rows"
— when the command printed **125 moved occurrences**. Corrected to 125 in the
same commit. That is the *same* evidence-typo class as H67 ("51 not 52") and
