## Judge (a): the milestone landed; the cost was four navigator defects, one per round

**P0 is complete and it was pairing that proved it.** `M5.30` had been stopped
for two cycles by a `Stop:` it could not answer; the cycle answered it twice: a
read-only census (`M5.47`) that said *the changed tile does not fit its chain*,
and then the real fix — `alloc_clusters` scanned all 115,200 FAT entries while
the BPB defines **115,185** data clusters, so any relocation could pick cluster
115,187 past the partition. With the BPB bound the M5.44 tile patches to a card
that passes `cardcheck` (480 files), `7z t` and `fsck.fat -n`, and whose diff is
**586 ranges / 152,815 B, outside 0** under `--allow-metadata`. That is the
first card on this project whose whole change set is enumerated.

**Every task in the batch shipped a defect on the first pass**, and the
navigators caught all four:
- **M3.27** — a fabricated register row: the table cited a `tst r5,r5` at
  `0x004259ee` that decodes (two independent tools) to `extu.w r0,r1`. The VA2
  `r5` was a local counter all along. This is the class the repo paid for
  before (EXP-20s): a plausible word written from expectation, not bytes.
- **M5.30** — the arithmetic said 115,187 clusters; the truth is 115,185 (last
  valid 115,186, 13 phantom entries). The code was right, the prose was wrong
  in five places, and the reproduction block patched a copy and proved nothing.
- **M5.47** — round 2 replaced a 242-line EXP with only a Corrections section.
  Round 3 restored the body and edited in place. A "fix" that deletes the
  evidence it corrects is the worst failure mode in an append-only record.
- **M5.48** — `_copy_factory_root` `rmtree`'d a pre-existing `--out`, so a user
  directory survived *by name* with its contents replaced. The task's EXP had
  claimed the tree was "not rolled back", implying file safety that was false.
  Now refused (exit 2, no report) with `--force-overwrite` as the opt-in.

**Pairing pays; the shape of the defect says it.** All four are invisible to a
`--selftest` (each passed its own tests) and visible to a second reader who

but every round produced a real fix, not churn. No solo task was in this batch,
