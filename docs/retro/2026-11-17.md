one was cosmetic:

## Process improvements

- **Skip/ignore sets are a gate-widening change.** M1.22 shipped a widened
  `US_BUILD_STARTS` that would have hidden a real EU citation. The navigator's
  cheap test — plant a real citation under one entry the set would hide and
  confirm the gate reports it — is now part of the review checklist in
  `prompt_tl.txt`, next to the existing negative-mutation rule.
- **Stale constants in prompts.** The QA prompt hard-coded a board error count
  that drifted (69 → 66). Replaced with "report the current count from the
  run"; a prompt must not encode a number the board moves.
- **Archive fixpoint.** PO has hit "archive fixpoint, 0 moved" for several
  passes because live `Depends`/`Unblock` still name done blocks. The PO prompt
  now states this exception ("unless every done block is still named by a live
  `Depends`/`Unblock`/`Re-opens`; then report `archive fixpoint, 0 moved`"), so
  PO does not re-derive it every pass.

## Prompt changes (before → after, with reason)

1. **`prompt_qa.txt`** — *Before:* "`todo_check.py` (default; `--strict`
   currently exits 1 on 69 board errors — report the count …)". *After:*
   "`todo_check.py` (default), `claims_check.py`. `todo_check --strict` exits 1
   on the board errors counted by H53 — report the current count from the run
   …". *Reason:* the literal 69 was stale (66 since H81) and is the exact
   number-rot the ledger bans; the board count belongs in the run, not the
   prompt.

2. **`prompt_tl.txt`** — *Before:* the review item had only the
   negative-mutation check for a gate/snapshot/artifact. *After:* it adds "When
   the diff **widens a skip/ignore set** (a build's address list, a NOMATCH
   allowlist), plant a real citation on one entry the set would hide and show
   the gate still reports it: a skip set for another build must contain only
   that build's addresses (M1.22)." *Reason:* M1.22's only shipped-class defect
   was exactly this; the existing mutation rule covered "a stored value
   disagrees", not "an allowlist grew".

3. **`prompt_po.txt`** — *Before:* "If TODO.md exceeds 1500 lines, archive is
   the first action before adding tasks." *After:* "… unless every done block
   is still named by a live `Depends`/`Unblock`/`Re-opens`; then report
   `archive fixpoint, 0 moved` in one line and continue." *Reason:* PO has
   reported the same fixpoint for several passes; the exception makes the rule
   honest instead of "over the line, blocked on live references".

No other prompt edits. `prompt_common.txt` is unchanged — its rule that any
task widening a standing gate is `Pair: required` already covers the M1.22
lesson, so the TL checklist is the right, narrower place for the test.
