## Prompt change (recorded; no silent edit)

### `prompt_tl.txt` — a `Pair: required` task needs two subagents, and the table names the navigator

**Before:**

```text
- Solo (exception, give the reason): … A task marked `Pair: required` is never run solo.
```

**After:** the same line gains:

```text
  `Pair: required` means two subagents (driver + a separate navigator); if you
  cannot launch both, leave the task `open` and say so in the log. The outcome
  table's mode column names the navigator — `one driver` is not a pair.
```

**Reason:** this cycle's M1.23 was `Pair: required` and ran with one driver and
the TL as reviewer (log: "pair required (one driver)"), so the required
navigator APPROVE never existed. The existing sentence forbade solo but the log
still called it a pair; naming the navigator in the table makes the
substitution visible to the SM instead of invisible.

No change to `prompt_common.txt`, `prompt_po/qa/se/sm.txt`: their runs followed
the prompts (SE's rule-15 audit and PO's archive-first no-op were exactly what
the text asks for), and `prompt_common.txt` already requires a log for a no-op
run.
