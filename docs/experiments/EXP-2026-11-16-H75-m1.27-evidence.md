## Interpretation

  `unique/different/nomatch` histogram; the histogram is the separate
  `match --va` command.
- **OBSERVED:** the `archive/us256.img` path is re-creatable on any checkout
  that has the vendor image (`head -c`, hash `70d945d8…`), so the path rule
  classifies it `vendor-pin` and the genuine set becomes empty.
- **FACT:** 22 was the count at `92550d6` (pre-clamp); the merge commit
  `2709645` prints 26. The EXP's dated body keeps 22; the Correction section
  and C-3704 record the merge-time 26.
- **UNKNOWN:** none. H62 (a `US256` fetch key) will replace the `head -c` line
  when it merges (follow-up).
