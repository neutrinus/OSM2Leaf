## Question

Besides the two region checks (map code, image A build name; M8.C1m,
M8.C1r) and the radio modules (M1.36), what differs between the EU and the
US 2011 cards? Which differences could still stop an EU card in a US unit?

## Hypothesis

The kernels are the same (M1.36), so all differences are in ROM A, in
`HDD_INFO` and in the map partition's regional data. **Falsifier:** a
difference in ROM B/C or in a non-regional file.

## Method

1. Manifests (names, sizes, SHA-256 of every file on the FAT32 partition):
   ```bash
   python3 tools/card_diff.py manifest archive/sd-images/LEAF_2011-2012_QSD-309-101_navi158_eu.img -o docs/research/card-manifests/eu2011.json
   python3 tools/card_diff.py manifest archive/sd-images/LEAF_2011-2012_US.img -o docs/research/card-manifests/us2011.json
   python3 tools/card_diff.py compare docs/research/card-manifests/eu2011.json docs/research/card-manifests/us2011.json
   python3 tools/card_diff.py compare docs/research/card-manifests/eu2011.json docs/research/card-manifests/us2011.json --depth 2 --detail SPEECH/US
   ```
   Each manifest took about 4 minutes (I/O bound).
2. System area: both images read in 1 MiB blocks up to the partition start
   (`0x06400400`), each block marked same / differs; differing blocks then
   compared in 512-byte runs.
3. The ROM C trailer located with `cerom.py --image-start 0x5200200 ... files`
   and `romhdr` (`physlast`).

## Observations

O1. **Counts.** EU 480 files / 5,173,965,667 B, US 248 files /
5,182,407,132 B. Exactly one path has the same bytes on both cards:
`CMP.LST` (19 B).

O2. **Per folder** (`compare`, depth 1; "only" = name on one card, "differ" =
same name, other bytes):

| Folder | only EU | only US | same | differ |
| --- | --- | --- | --- | --- |
| root | 0 | 0 | 1 | 2 (`DRSTR001`, `MMAIN001`) |
| `BICON001` | 0 | 0 | 0 | 1 |
| `MAPAL001` | 45 (3,445 MB) | 112 (2,820 MB) | 0 | 1 (`LEV3456R`) |
| `OPNG` | 1 | 1 | 0 | 0 |
| `RDSTM001` | 0 | 0 | 0 | 2 |
| `REFER001` | 278 (596 MB) | 6 (1 MB) | 0 | 110 (826 / 2,215 MB) |
| `REFER002` | 15 | 1 | 0 | 1 |
| `SPEECH` | 21 (198 MB) | 6 (61 MB) | 0 | 0 |
| `TMC` | 1 | 0 | 0 | 0 |
| `VER_INFO` | 0 | 0 | 0 | 1 |
| `XMD` | 0 | 3 | 0 | 0 |

O3. **Voices.** EU `SPEECH/{BE,DU,FR,GE,IT,PT,SP}`, US `SPEECH/{US,CF}`;
each language has `GID/S<ll>00000.GID`, `TTS/T<ll>00000.TTS`,
`VR/V<ll>00000.AGM`. No language is on both cards.

O4. **Opening image.** EU `OPNG/MKR_OPNG/NISSAN/OIXXEVNI.001`, US
`.../OIXXNVNI.001`, same size 1,606,224 B. NK1 and ROM B carry the pattern
`OIXXXXXX` (NK1 file offset `0x2c77e0`; card `0x04415ce0` and its copy
`0x04e15ce0`; ROM C's own `OIDEFALT.img` and the `BASSB` blob also hold
`OIXX`), so the name is most likely matched by pattern; the NK1 + EU card run
of M8.C1r showed the opening logo.

O5. **`HDD_INFO.TXT`.** EU `QSD-302-100 / QSD-309-101 / 02-110100-00 /
SDC08-EVEUR / 11-05 / 470323501005`; US `QSD-301-100 / QSD-301-103 /
02-100100-00 / SDC08-EVNAM / 10-30 / 470282203030`. The raw copy at
`0x06000000` matches the file on each card.

O6. **System area.** Blocks (MiB): 0 same; 2–25 and 32–55 (ROM A and its
copy) differ; 62–68 and 72–78 (ROM B, copy) same; 82–87 (ROM C) same; 88
differs in one run `0x05868400`–`0x05868600`, which is 39 bytes at
`0x058685d9`–`0x058685ff` on the EU card (zeros on the US card), right after
ROM C's `physlast` (`0x886683d8` → file `0x058685d8`, the end of the last
ROM C file `OIDEFALT.img`); 92 (`BASSB` at `0x05c00000`) same up to
`0x05d88600`, then EU pads `0x00`, US `0xff`; 96 is the `HDD_INFO` copy.

## Interpretation

The hypothesis holds: ROM B and C are the same bytes; everything else that
differs is either ROM A or regional data. The 39 bytes after ROM C are
outside every module and file of ROM C, so they cannot change what runs
(they look like leftovers in the EU card's write buffer).

For an EU card on a US unit, after `card_mapcode.py` the remaining
regional gap is the voices: the EU card has no `US`/`CF` folder. The XM data
is radio and out of scope.

## Conclusion

The EU and US 2011 cards share their kernels and one file. The differences
that matter for an EU card in a US unit are the two region checks (already
handled) and the voice folders (open: M1.55). Details:
[eu-us-card-diff.md](../research/eu-us-card-diff.md).
