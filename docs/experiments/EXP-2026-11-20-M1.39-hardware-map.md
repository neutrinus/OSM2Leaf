# EXP-2026-11-20-M1.39: hardware map of the head unit, read from the ROM registry and driver strings

- **Status:** done (firmware-side map; no board was opened)
- **Date:** 2026-11-20
- **Sample:** `US256` (first 256 MiB of the US 2011 card), SHA-256
  `70d945d823f93f04cae4e6c7113a723cae3a992ab7a6f9b24e94ce2e006a04da`

## Question

## Method

```bash
python3 tools/fetch_image.py --image US256 -o $S/us256.img
python3 tools/cerom.py --image-start 0x3e00200 $S/us256.img romhdr      # build B
python3 tools/cerom.py --image-start 0x200200  $S/us256.img romhdr      # build A
python3 tools/cerom.py --image-start 0x3e00200 $S/us256.img extract-file default.hv -o $S/hw/default.hv
python3 tools/cehive.py $S/hw/default.hv | grep -E '^Drivers\\(Launch|USB)|Automotive\\Graphic'
```

Port users: a scratch script searched the image for the UTF-16 strings
`SCIn:`, `UATn:`, `COMn:` and mapped each hit to the module section that
contains it (`cerom.py sections` of every module of builds A and B; only
uncompressed sections can hit, so a missing user is not proof of no user).

## Conclusions

1. RAM: the firmware addresses DRAM from `0x08000000` to `0x0e600000`
   (102 MiB). The board size is not stated anywhere; 128 MiB is the guess.
   Applications get `0x09e40000`–`0x0cae1000` = 44.6 MiB.
2. `SCI6:` is the debug shell's port, and SCIF channel 6 is `0xffe46000`,
   the address the kernel's debug writer polls (EXP-37). Two independent
   finds give the same channel: the debug console is SCIF6.
3. The unknown block at `0xffe70000` that stops the kernel boot in QEMU
   (it polls `+0x808`) contains the OHCI registers at `+0x400`: it is the USB
   host block (controller + PHY/clock control). This closes one open question
   of `full-system-emulation.md`.
4. The SH-4 reaches the vehicle CAN through a UART (`UAT3:`), so a separate
   microcontroller (the one `VCANSubMiconUpdate.exe` updates) sits on the bus.
5. Bluetooth is a UART module on the high-speed SCIF.
6. The audio microcontroller link is `SCI1:` and carries much more than
   audio (tuner, TMC, antitheft, update, product test).
