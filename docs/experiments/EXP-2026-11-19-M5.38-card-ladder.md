## Question

What does a card contain at each ladder step P0–P4, which inconsistencies
will the firmware see at each, which generated files have no L3 gate — and,
for the next step P1, how much of the region can today's writer actually
fill?

## Hypothesis

P1 ("all Dolnośląskie display-only") is a P0 rerun over a bigger bbox: the
census says the region is inside one tile (`contained=1`, M5.46), so P1 is the
same pipeline on more directories. **Falsifier:** some directory over the
region has a kind the writer refuses, so P1 cannot be built by repeating P0.

## Method

1. **Sample.** The factory tree and tile above.
2. **Commands** (repo root; `FAC=/home/user/scratch/factory-eu`):

```bash

```

3. **Controls.** *Positive:* the P0 window `16.40,51.10,16.45,51.13` (the
   M5.44 splice that is on the built card) must count only spliceable
   directories (1 level-1 + 1 level-2). *Negative:* `card_ladder.py
   --selftest` asserts that an untagged block, an invalid step `P7`, and a
   pending row for an already-tagged or closed block all make `--check`
   fail; before tagging, `steps --check` on this board printed
   `missing=55` and exited 1.
4. **Scope.** One tile (`B48R058R`), sections 1/2/4, the profile bbox
   `14.0,49.9,17.9,51.9`. Box intersection uses the directory's WGS84 box from
   `parcel_census` (`clarion_bg.parcel_geo`, level 2 = 4×4 meshes, M5.44); a
   box that only touches the bbox edge is not counted. Board scope: blocks
   whose ID starts `M4.`/`M5.`/`M9.` and are not `[x]`/`done` (55 after this
   task closes; 56 after the rebase onto M3.11c's merge, which added an open M5.52).
5. **Falsifier.** As in the hypothesis: any `preserve-only` or `unmodelled`
   directory in the region count.

## Interpretation

- **FACT:** the Dolnośląskie bbox intersects 20 section-1 directories of
  `B48R058R`; 11 are kinds `tilewriter` refuses to mutate. The hypothesis is
  **refuted**: P1 is not "P0 over a bigger bbox" — 9 of 20 can be filled, the
  rest need M5.53.
- **OBSERVED:** P0's own window is fully spliceable (control), so the P0
  result is not affected.
- **HYPOTHESIS (unchanged, M5.22):** the preserve-only kinds hold non-zlib
  records; why, and whether they can be rewritten, is M5.53's question.
- **Decision (not a fact):** P2 = routing, P3 = names, reversing the order
  M5.38's block proposed, to keep the merged gate page (M5.50) and the board's
  critical path valid. Reasons on the page.
