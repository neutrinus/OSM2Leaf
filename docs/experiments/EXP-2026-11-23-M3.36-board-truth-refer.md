## Method

1. **Sample and hash.** The board at `origin/main` before the edits is pinned
   by `git show origin/main:TODO.md > "$S/todo-before.md"`; no firmware image
   or card image is involved.

2. **Commands.** 
   ```bash
   S=/home/marek/projekty/leafre-work/scratch/m3.36
   python3 tools/board_truth_audit.py --selftest
   git show origin/main:TODO.md > "$S/todo-before.md"
   python3 tools/board_truth_audit.py "$S/todo-before.md" \
       --scope M3.29,M3.30,M4.23,M3.13,M3.14,M3.16,M4.49
   python3 tools/board.py next-id M3          # M3.43
   python3 tools/board.py next-claims         # C-8850–C-8859
   python3 tools/board.py add-task "$S/new-task.md"
   python3 tools/board.py add-claims --section \
       "M3.43 — L4 zoom-out INTER/FRWAY reader observation (C-8850–C-8859)" \
       --create --file "$S/claims-rows.md"
   python3 tools/board.py field M3.29 Blocker "<0x1507 undelivered; 0x14b5 never issued>"
   python3 tools/board.py field M3.29 Unblock "**M3.43** — L4 QEMU zoom-out …"
   python3 tools/board.py status M3.29 blocked
   python3 tools/board.py field M3.30 Depends "M3.43 (L4 QEMU zoom-out produces the per-family reads); …"
   python3 tools/board.py field M3.30 Blocker "<M3.29 cannot deliver the record request>"
   python3 tools/board.py field M3.30 Unblock "M3.43 (produces the per-family reads in L4) …"
   python3 tools/board.py status M3.30 blocked
   python3 tools/board.py field M3.16 Unblock "**M3.43** — L4 QEMU zoom-out observes the INTER/FRWAY content reader …"
   python3 tools/board.py field M3.18 Unblock "**M3.43** — L4 QEMU zoom-out observes the ICADM/ZIPFR content reader …"
   python3 tools/board.py field M3.14 Unblock "**M3.43** — L4 QEMU zoom-out on NK1 is the live unblocker …"
   python3 tools/board.py unfield M3.14 Unblock --match "M3.29 (open)"
   python3 tools/board_truth_audit.py \
       --scope M3.29,M3.30,M4.23,M3.13,M3.14,M3.16,M4.49
   python3 tools/todo_check.py "$S/todo-before.md"
   python3 tools/todo_check.py
   python3 tools/board.py lost --base origin/main
   ```

3. **Controls.** *Positive: * `board_truth_audit --selftest` synthetic text with
   one stale done-pointer and one false `(done)` returns `1 A, 1 B`; the real
   board before the edits returns the same two classes. *Negative:* after the
   edits the scoped audit returns `0/0` and exits 0; `lost --base origin/main`
   exits 0; `todo_check` warning count is unchanged. A lost ID or a new
   warning would have falsified the pass.

4. **Scope.** `TODO.md` task blocks M3.29, M3.30, M3.14, M3.16, M3.18 and the
   new M3.43, plus ten reserved claim rows C-8850–C-8859. M4.23 (already
   `Unblock: M4.24`, a live blocked task) and M4.49 (`Unblock: M4.51`, live)
   were checked and **not edited**. No `Done when`/Goal/Scope of an existing
   task was rewritten; no existing claim row was touched. The audit is
   deliberately limited to the seven task IDs in the task's Scope.

5. **Falsifier.** Any of: scoped audit count > 0 after the edits, `board.py
   lost` reporting an ID, `todo_check` warnings above the baseline, or a
   changed `Done when`. All four were checked.
