## Corrections after navigator review

The navigator verified every census number and found four record defects and
one unrunnable `Precheck`; all are fixed in this branch. The three controls
below are what makes the fix checkable.

### Defects fixed

- **The `Precheck` was unrunnable.** `python3 tools/cardcheck.py --selftest` is
  not a flag (`cardcheck.py: error: one of the arguments --image --root is
  required`, exit 2). The block now names `python3 tools/selftest.py --only
  cardcheck` (`passed=1 failed=0 skipped=0` / `selftest: OK`) and
  `python3 tools/cardcheck.py --root ~/projekty/leafre-work/m5.29-factory-root
  --fast` (`RESULT: PASS`). This was a task-block wording defect, not a tool
  defect; no code changed.
- **C-4562 said `DRSTR001.DAT` was "unchanged".** It keeps its 11,968 B
  **length** but its **bytes** differ (first differing byte 1693, SHA-256
  `2b7f2fb8…25f6` -> `307cca5d…3f17` at level 1 and `d75b9929…9315` at
  level 2). The claim now says "same directory size 11,968 B (delta 0, slack
  53,568 B), bytes differ (MAPAL001 node value)" and points to C-4569.
- **"The only changed file" was ambiguous.** This record now defines
  **changed = non-zero delta** and says so in §4 and in the Interpretation:
  by that measure one file changes per tree; by **bytes** two files differ
  (`DRSTR001.DAT` and the tile), matching both `report.json`
  `tree_diff.differing_files` lists. M5.30 must not read "479 unchanged" as
  "479 byte-identical".
- **§6 mislabelled `7654560768`.** It is `data_offset + 115185 × 65536`
  (data-area end, `0x1c83f5400`), not the partition end; `_check_envelope`
  compares against the partition end `7654605824` (`0x1c8400400`, 45,056 B
  further). The block now prints `nclusters`, `data_area_end` and
  `partition_end` and says which one the guard uses.
- **C-4567 used hand arithmetic** ("209x and 6x"). The ratios are gone; the
  claim quotes the deltas and slacks the tool prints (`+4,671,350` vs
  `22,272`; `+138,994` vs `22,272`).

### Controls (commands and output)

**A. The census's allocator prediction is the allocator `imgpatch` runs**
(C-4568). Spy on `mkcard.alloc_clusters` during `imgpatch._build_plan` and
compare the list with `fit_census.allocation_check` on the same FAT, chain and
hint:

```bash
python3 - <<'EOF'
import sys; sys.path.insert(0, 'tools')
import mkcard, imgpatch, fit_census
IMG = '/home/marek/projekty/OSM2Leaf/archive/sd-images/LEAF_2011-2012_QSD-309-101_navi158_eu.img'
data = open('/home/marek/projekty/leafre-work/m5.34/out/MAPAL001/B48R058R.DAT', 'rb').read()
origin, calls = mkcard.alloc_clusters, []
def spy(fat, count, start_hint=2):
    out = origin(fat, count, start_hint=start_hint)
    calls.append((count, start_hint, list(out)))
    return out
mkcard.alloc_clusters = spy
try:
    with open(IMG, 'rb') as h:
        part, geo, fat = mkcard.open_map_partition(h)
        imgpatch._build_plan(h, geo, fat, 'MAPAL001/B48R058R.DAT', data,
                             allow_resize=True, update_version_copy=False)
except imgpatch.PatchError as exc:
    print('imgpatch refusal:', exc.reason)
finally:
    mkcard.alloc_clusters = origin
need, hint, extra = calls[0]
with open(IMG, 'rb') as h:
    part, geo, fat = mkcard.open_map_partition(h)
    info = imgpatch._locate(h, geo, fat, 'MAPAL001/B48R058R.DAT')
chain = mkcard.chain(fat, info['cluster'])
pred = fit_census.allocation_check(fat, chain, need,
                                   fit_census.first_valid_cluster(part, geo),
                                   chain[-1] + 1)
print('need', need, 'start_hint', hint, 'chain_last+1', chain[-1] + 1)
print('imgpatch.extra[:5]', extra[:5], '...[-3:]', extra[-3:], 'n', len(extra))
print('census.alloc[:5]', pred['allocator_clusters'][:5], '...[-3:]',
      pred['allocator_clusters'][-3:], 'n', len(pred['allocator_clusters']))
print('IDENTICAL', extra == pred['allocator_clusters'])
print('outside_partition', pred['allocator_outside_partition'],
      pred['allocator_outside_range'])
EOF
```
