## Method

2. **Commands.** Runnable as written, from the repository root:

   ```bash

       --json /home/marek/projekty/leafre-work/scratch/m5.81/run-us.json
   ```

   The runner invokes each committed `*_decode.py census` as a subprocess and parses the headline counters with stable string anchors quoted from each tool's own `print` statements (e.g. zcode `shard: form A size N records N record_base 0x… explained N/N`, icode `bytes explained: N / N = N%`, inter `TOTAL EU: N shards, N records, N B`, frway `bytes: N of N explained (N%)`, icadm `CARD TOTAL: shards=N … explained=N B = N%`, zipfr `bytes explained N/N = N %`). No grammar is re-derived and no line number is used as a key.
3. **Controls.** *Positive:* all six `*_decode.py --selftest` pass (`all ok`/`OK`/`PASS`), and each real census prints > 0 bytes explained on every shard its earlier EXP marks fully explained — e.g. EU ZIPFR001 `520448/520448 = 100.0 %`, US ICODE001 `6059118/6071808 = 99.791%`. *Negative:* (a) the runner's own `--selftest` proves a garbled/missing headline raises FAIL and that a present shard reporting `explained 0/N` is flagged, not absorbed as `absent`; (b) each decoder's own mutation flag on a real shard is detected (below); (c) pointing the runner at a missing tree exits 2. A negative without a positive control is not claimed.
4. **Scope.** EU2011 33 ZCODE + 1 ICODE + 33 INTER + 26 FRWAY + 33 ICADM + 1 ZIPFR `.cmp/.ind` pairs = 56,487,168 + 111,378,432 + 303,629,312 + 2,921,728 + 113,561,600 + 520,448 decoded bytes; US2011 0 + 1 + 11 + 11 + 11 + 0 pairs = 6,071,808 + 225,175,552 + 5,141,760 + 6,274,816 decoded bytes. ZCODE/ZIPFR are absent on US (0 files) — recorded as `absent`, excluded from the falsifier. No firmware code, no 2014/2016 card, no format grammar change.
5. **Falsifier.** A decoder whose factory total is 0 bytes explained on a shard its EXP reports as fully explained. The runner maps a present shard with 0 explained to FAIL. Second falsifier: any real shard's explained bytes disagreeing with its EXP — listed with both numbers in Observations (none found here).
