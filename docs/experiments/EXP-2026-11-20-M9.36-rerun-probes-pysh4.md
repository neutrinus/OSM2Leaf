R0,@(disp,Rn)`, `mul.l`, `movca.l`; M9.37/M9.48/M9.49/M9.50/M9.51 `div0s`,

## Hypothesis

A recorded result can only change if its run executed an instruction whose
outcome differs between the engine it ran on and the current engine (PySh4 is
deterministic: the paths are identical up to the first such instruction).
Expected: the `drstr-sub_00419350` stop `UNMAPPED 0xfffffec6..0xfffffec8`
(M9.35) moves, because it has the shape of a 2-byte store through a small
negative `r0` (C-3489); every other recorded verdict stays.
**Falsifier:** a run with 0 exposed instructions whose result differs from the
record; the engine-only swap leaving the `drstr` stop where it was; any run
recorded after H51 executing one of the 1,147 halfwords changed after H51.
