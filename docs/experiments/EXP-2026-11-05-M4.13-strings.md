writer rule for unsupported characters.

## Writer rule (unsupported characters)

- Encode strings as ISO-8859-2. Characters outside that set cannot be written.
  The rule is to reject them, not to substitute, because no such character occurs
  in this database (decode errors 0).
- Maximum observed length 151 bytes. The firmware's own length limit per field is
  UNKNOWN (not read here).
- Collation: the order of strings within streams was not established. Sampled
  streams are not in byte order. Locale collation is UNKNOWN.

## Limits

- The text rule is a filter, so counts depend on it.
- Per-field counts need the record framing (rdstm.md ranked unknown 3, not decoded).
