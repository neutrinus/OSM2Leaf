## Question

Does a section-2 graph that the writer (`rd_encode.build_record_edges`) emits
into a factory tile decode back, through the reader (`clarion_rd.parse_record`),
to the same nodes and links — and does a check built on that comparison fail
when one endpoint moves or one link is missing, and say `preserved` (not
"match") for a section 2 nobody emitted?

## Hypothesis

At the framing level the round trip is exact: parcel, node multiset, link
`(id, start, end)` with the `0x2000` end flag naming the end, and parcel-edge
entries `(node, side, twin)`. **Falsifier (stated before the run):** the check
reports PASS for a tile whose emitted graph has one link fewer than the tile,
or one endpoint moved; or a tile with no emitted record (factory section 2) is
reported as a graph match rather than `preserved`.

## Method

1. **Sample and hash.** `F` is the factory tile above; `sha256sum $F` must
   print `e9c9cb22…3ff52`. `W` is a scratch directory outside the repo.
2. **Commands.** From the repository root:

```bash

FROOT=/home/user/scratch/factory-eu
F=$FROOT/MAPAL001/B48R058R.DAT
sha256sum $F
# precheck
python3 tools/ze0-viewer/harness.py info $F
python3 tools/tile_diff.py --selftest
grep -rn 'section 2\|sec2\|graph' tools/ze0-viewer/tools_ze0/clarion_tile.py   # on main: no hits
python3 tools/tile_graph_roundtrip.py --selftest
# factory: decode -> writer -> decode for every unit-0 record
python3 tools/tile_graph_roundtrip.py reemit $F --json $W/reemit-factory.json
# the real splice (section 1 only; section 2 must come out preserved)
python3 tools/osm_ingest.py tools/fixtures/m5.37-splice.osm -o $W/splice.imf.jsonl
python3 tools/mesh_split.py $W/splice.imf.jsonl -o $W/splice.split.jsonl
mkdir -p $W/splice $W/inj $W/neg
python3 tools/tilewriter.py $W/splice.split.jsonl --cell B48R058R --factory $F \
    --country 616 --out $W/splice/B48R058R.DAT --json > $W/splice-write.json
python3 tools/tile_graph_roundtrip.py check $W/splice/B48R058R.DAT --factory $F --json $W/check-splice.json
python3 tools/tile_graph_roundtrip.py check $F --factory $F --json $W/check-factory.json
# emitted graph on the real splice: 32 level-1 records of dir 76,940
python3 tools/tile_graph_roundtrip.py inject $W/splice/B48R058R.DAT --out $W/inj/B48R058R.DAT \
    --graph-out $W/emitted.json --dir 76,940 --count 32
python3 tools/tile_graph_roundtrip.py check $W/inj/B48R058R.DAT --emitted $W/emitted.json \
    --factory $F --json $W/check-inj.json
# negative controls
python3 tools/tile_graph_roundtrip.py mutate $W/inj/B48R058R.DAT --graph $W/emitted.json --out $W/neg/B48R058R.DAT
python3 tools/tile_graph_roundtrip.py check $W/neg/B48R058R.DAT --emitted $W/emitted.json \
    --factory $F --json $W/check-neg-moved.json
python3 tools/tile_graph_roundtrip.py drop-link $W/emitted.json --out $W/emitted-minus1.json
python3 tools/tile_graph_roundtrip.py check $W/inj/B48R058R.DAT --emitted $W/emitted-minus1.json \
    --factory $F --json $W/check-neg-drop.json

# the same through l2check (card roots hold a symlink MAPAL001/B48R058R.DAT to each tile)
for r in inj neg splice; do mkdir -p $W/root-$r/MAPAL001; ln -sf $W/$r/B48R058R.DAT $W/root-$r/MAPAL001/B48R058R.DAT; done
python3 tools/l2check.py --root $W/root-inj --partial --no-golden --no-cmp --skip-mutation \
    --tiles , --semantic-tiles , --graph-tiles B48R058R.DAT --graph-emitted $W/emitted.json --graph-factory $FROOT
python3 tools/l2check.py --root $W/root-neg --partial --no-golden --no-cmp --skip-mutation \
    --tiles , --semantic-tiles , --graph-tiles B48R058R.DAT --graph-emitted $W/emitted.json --graph-factory $FROOT
python3 tools/l2check.py --root $W/root-splice --partial --no-golden --no-cmp --skip-mutation \
    --tiles , --semantic-tiles , --graph-tiles B48R058R.DAT --graph-factory $FROOT
```

3. **Controls.** *Positive:* the synthetic fixture (two level-1 parcels,
   8 nodes, 7 links, 2 edge entries, laid into a one-section tile by
   `clarion_tile.write_tile`) checks PASS 2/2; the factory tile against itself
   is `preserved` 73,416/73,416. *Negative:* one endpoint moved (`x` +1 in one
   injected record), one emitted link dropped from the graph, an injected tile
   checked with no emitted graph (32 records changed, none claimed), plus in
   the selftest a reversed link and a changed edge side. Each must be FAIL.
4. **Scope.** One tile, `B48R058R.DAT`, section 2 only: 65,274 level-1 and
   8,142 level-2 records (4,071 unit-0 + 4,071 part b) = 73,416 records.
   `reemit` covers the 69,345 unit-0 records; the 4,071 part-b records are
   compared only byte-for-byte against the factory (grammar UNKNOWN,
   M4.23/M4.24). The injected fixture covers 32 records of section-1 dir
   `y=76 x=940` (level 1). Levels 4/5 (`LEV3456R`) are out of scope.
   *Compared:* absolute parcel `(row, col)` from the parcel code, node
   multiset `(x, y)`, links `(id, start, end)` (end = the `0x2000` entry; the

   bits, twin word)`, and the three counts. *UNKNOWN, never compared:* code
   bits outside `rowcol` (w0 bit 15), `w4`, `w5` (one-way bits, regulation
   words), class word, cost words, countries, part b.
5. **Falsifier.** As stated under Hypothesis.

## Interpretation

- **FACT:** at the framing level (parcel, nodes, links with direction, edge
  entries) the writer's output decodes back to exactly the emitted graph on
  the synthetic fixture (2/2) and on 32 records injected into the real splice
  (32/32), and on 67,674/67,674 factory records that the writer can express.
- **FACT:** the check is not vacuous: a one-unit endpoint move, a one-link
  difference and an unclaimed change each FAIL; an untouched section 2 is
  `preserved`, never `PASS`.
- **OBSERVED:** 1,671 factory records (2.4 %) hold entries whose far node is
  in another record (`other & 0x4000`); the writer has no way to emit those.
  57,565 records reuse a link id across link classes; the reader pairs ends by
  `(id, class low byte)`, so a writer that gives every link one class word
  must renumber.
- **OBSERVED:** factory w0 bit 15 is set on every section-2 parcel code;
  `clarion_bg.parcel_code` never sets it.
- **UNKNOWN:** whether the firmware routes on any of this (L3/M5.16); what
  `w4`, the class word, cost words, regulation words and part b mean to the
  router.
- **HYPOTHESIS:** the injected fixture pads a shorter zlib stream with zeros
  to the old span. The reader (`zlib.decompress`) ignores the padding; whether
  the firmware's inflater does is untested. It is a fixture property, not a
  writer property.

## Conclusion

`tools/tile_graph_roundtrip.py` and the `l2check` check `tile_graph_roundtrip`
(`--graph-tiles`, `--graph-emitted`, `--graph-factory`) are the L2 golden for
section 2: an emitted graph JSON is compared with what the tile decodes to,
and every record not emitted must equal the factory. Done-when is met: PASS on
the synthetic fixture and on the real splice with an emitted graph, FAIL on a
moved endpoint, `preserved` for an untouched tile. The edge-attribute layer is
`UNKNOWN` and not compared. No format claim changes; `reader-coverage.md`
row 18 gains the L2 check. Claims C-5160–C-5166.
