### S1 — writer-inverse structural signature (record framing)

**Derivation (explicit, from parse artifacts):** `lctbl_records.py stats` on hashed stock sample shows 247,089 records with invariant marker byte `0x01` at record offset `+2`, BE size framing (`size_words` at `+0`, size `2*size_words`), and header length bytes at `+3..+6` (rdstm.md/C-1832/C-1839, consistent with parse). Signature family targets marker test: SH4 `mov.b @(2,Rm),R0` = `1000 0100 mmmm 0010` (LE 16-bit word mask `0xF0FF == 0x8402`) co-occurring with `cmp/eq #1,R0` (`0x8801`, LE bytes `01 88`) within a 40-byte window (either side) in executable plain bytes. (Derived from record invariant, not from `refer.md`/`rdstm.md` prose grammar search.)

**Scan command (reproducible):**

```bash
python3 - <<'PY'
import struct
from pathlib import Path
img = Path('archive/head256.img').read_bytes()
modules = [
  ('Navi.exe sec0', 0x00c8f200, 0x0054bd16, 0x00011000),
  ('OBJDLL.dll sec0', 0x007de200, 0x0005563b, 0x03481000),
]
def scan_s1(data, va0, window=40):
    hits=[]
    for i in range(0, len(data)-2, 2):
        w = struct.unpack_from('<H', data, i)[0]
        if (w & 0xF0FF) == 0x8402:
            lo=max(0,i-window); hi=min(len(data)-2,i+window+1)
            for j in range(lo,hi,2):
                if j==i: continue
                if struct.unpack_from('<H', data, j)[0] == 0x8801:
                    hits.append(va0+i); break
    return sorted(set(hits))
for name,foff,ln,va0 in modules:
    data = img[foff:foff+ln]
    s1 = scan_s1(data, va0, 40)
    print(f'MODULE {name} file_off=0x{foff:x} va=0x{va0:x} bytes={ln}')
    print(f'  S1 window40 count={len(s1)} vas={[hex(v) for v in s1]}')

```

### S2 — writer-inverse structural signature (slot length bytes / string slots)

**Derivation (explicit, independent invariant set):** `lctbl_records.py stats` / record layout gives four slot length bytes at `+3..+6` defining name slot sizes `2*lenN` (four name slots after 16-byte header; 456,501 non-empty slots across 247,089 records). Signature family targets code reading those four adjacent length bytes from a common base: presence of `mov.b @(d,Rm),R0` for all `d in {3,4,5,6}` with the same base register `Rm` (`0xF0FF in {0x8403,0x8404,0x8405,0x8406}`) within an 80-byte window. (Derived from slot-length layout invariant, independent of S1's marker test.)

**Scan command (reproducible):**

```bash
python3 - <<'PY'
import struct
from pathlib import Path
from collections import defaultdict
img = Path('archive/head256.img').read_bytes()
modules = [
  ('Navi.exe sec0', 0x00c8f200, 0x0054bd16, 0x00011000),
  ('OBJDLL.dll sec0', 0x007de200, 0x0005563b, 0x03481000),
]
def scan_s2(data, va0, window=80):
    by_rm = defaultdict(lambda: defaultdict(list))
    for i in range(0, len(data)-2, 2):
        w = struct.unpack_from('<H', data, i)[0]
        if (w & 0xF0FF) in (0x8403,0x8404,0x8405,0x8406):
            rm = (w >> 8) & 0xF
            d = w & 0x00FF
            by_rm[rm][d].append(i)
    hit_anchors=set()
    for rm, dm in by_rm.items():
        if not all(d in dm for d in (3,4,5,6)): continue
        allpos = sorted([(p,d) for d in (3,4,5,6) for p in dm[d]])
        ps = [p for p,d in allpos]
        for idx,p in enumerate(ps):
            seen=set(); j=idx
            while j < len(allpos) and allpos[j][0]-p <= window:
                seen.add(allpos[j][1]); j+=1
            if seen >= {3,4,5,6}:
                hit_anchors.add(p)
    return sorted(va0+p for p in hit_anchors)
for name,foff,ln,va0 in modules:
    data = img[foff:foff+ln]
    s2 = scan_s2(data, va0, 80)
    print(f'MODULE {name} file_off=0x{foff:x} va=0x{va0:x} bytes={ln}')
    print(f'  S2 window80 count={len(s2)} vas={[hex(v) for v in s2]}')
PY
```
