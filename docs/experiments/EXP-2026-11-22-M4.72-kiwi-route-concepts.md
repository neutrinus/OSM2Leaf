## Question

Can the KIWI route-planning concepts (node, link, link cost, regulation, upper-level correspondence) name and validate fields of our section-2 routing graph, given that no KIWI specification text is available yet (M4.65)?

## Hypothesis

`kiwiread` names almost no route-planning structures (only flags in the road frame and a "level of route planning data" word), so the expected outcome is the task's Stop branch: a concept table plus numeric tests, with no confirmed field. **Falsifier:** a section-2 field correlates strongly with drawn geometry length (|r| > 0.8 over a counted sample), which would identify a KIWI-style link cost.

## Method

2. **Commands.**

   ```bash
   grep -n -i -E 'route|plan|link cost|correspond' /home/marek/projekty/leafre-work/scratch/m4.72/kiwiread/kiwiread.c | head -40

   ```
3. **Controls.** *Positive for the tool:* Pearson on synthetic +1/-1/0 series must be exactly 1, -1, 0. *Negative:* a field with |r| below 0.8 is not identified as a link length. *Prior:* `route_link_join.py sec1` already showed that section-2 `w4`, `w5`, `a` and `b` are not join keys (C-5150–C-5156).
4. **Scope.** One tile, level-1 section 2, sampled every 16th record. Excluded: `LEV3456R` levels 3–6 (no KIWI field to compare), section 4, a real KIWI disc (M4.77), firmware VAs and copying GPL code.
5. **Falsifier.** |r| > 0.8 for `b` against geometry distance, stated before the run.

## Interpretation

- **FACT (tool):** section-2 word `b` has only r=0.1035 against straight-line node distance over 130,212 links, and `a` has r=0.0363. Both are far below the 0.8 falsifier, so neither is identified as a KIWI-style link length/cost from the concepts alone.
- **OBSERVED:** node degrees are small integers (1–7, dominated by 2 and 3), consistent with a road graph; this validates the corpus but names no KIWI field.
- **UNKNOWN:** no upper-level correspondence field was identified; the KIWI chapter that defines route-planning records and the level-up pointer is needed (M4.65). The LEV3456R comparison cannot be run without that chapter.
- **Process:** no KIWI field was confirmed, so no field was written into `docs/format/map-tiles.md` and no `Unblock:` line was added to M4.40/M5.57. They stay blocked on the firmware readers (M4.55/M9.65), not on this task.
