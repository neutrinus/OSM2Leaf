## Question
Can we produce a repeatable first Poland compiler milestone where exactly one tile (`B48R058R`, Wrocław area, Dolnośląskie test slice) is OSM-generated with `mapping=provisional-v0` and swapped into a factory-EU-like context, validated offline with an explicit L1+L2 acceptance-gate report (operationalizing M5.11), without committing vendor bytes?

## Hypothesis
The existing toolchain (`osm_ingest` → `mesh_split` → `roadclass_v0` provisional table → `tilewriter` → `rebuild_manifests` → `cardcheck`/`l2check`) can generate `B48R058R.DAT` from a small synthetic OSM fixture and produce an honest per-gate report. A factory-backed run (one tile swapped into factory EU, rest verbatim) requires factory EU tile/tree context; if unavailable (rule 11 / Stop), a synthetic-only path is produced and the real-image/factory run is marked `blocked` with the missing input named.

## Method
1. Ingest synthetic OSM → IMF v1 (`osm_ingest.py`).
2. `mesh_split.py` on IMF (fallback to IMF if split not needed).
3. Generate provisional class table `ze0-road-class-table/1` via `roadclass_v0.py --class-table-out` (`mapping=provisional-v0`).
4. Write `MAPAL001/B48R058R.DAT` via `tilewriter.py` (`--cell B48R058R --class-table ... --country 616 --data-version 26/11/09/01`, synthetic/no-`--factory` path). **This is the only OSM-generated tile.**
5. Build a synthetic baseline scaffold (non-OSM-generated, no vendor bytes) with `MMAIN001.DAT`, `LEV3456R.DAT`, `B30R060R.DAT`, `REFER001/POINT001.DAT.{cmp,ind}`, `CMP.LST`, `DRSTR001.DAT` stub (helpers modeled on `rebuild_manifests` synthetic patterns) so manifests/checks can be attempted.
6. `rebuild_manifests.py --root <out> --partial`.
7. `cardcheck.py --root <out> --partial --ignore-dump-artifacts --fast`.
8. `l2check.py --root <out> --partial --no-golden --no-cmp --tiles B48R058R`.
9. Emit per-gate report with statuses `PASS` / `NOT-APPLICABLE` / `CANNOT-VERIFY-OFFLINE` / `NEEDS-L3` (SKIP never PASS).

