## Question

Which MAPAL001 tile sections does the renderer read, and which are ignored (or read by other subsystems)? Section 4 (admin/place-name index) especially.

## Hypothesis

Exploratory. From format docs: section 1 holds display geometry (road-shape/background), LEV3456R section 2 is the router graph, section 4 is a place-name index (not geometry). Expect MAP/display path to read section 1; RGD/router path to read LEV section 2; section 4's render-time use unclear.

- MAP `0x00425f40`: `0x004260ca jsr @r3 → 0x0041ee14`
- RGD `0x004266ec`: `0x00426850 jsr @r3 → 0x0041ee14`
- Other callers include `0x004259bc` (M3.5 START), `0x0042752c`, `0x00425da4` (init, loads type desc `@(8)=0x0fa0,@(10)=0x258` at 0x425df8-0x425e0a and calls 0x0041ee14 twice), `0x0042a9e4`.

### RGD/MAP distinction (cross-ref)

MAP_DATA = map display data; RGD_DATA = routing/guide data (strings "RGD MESH_ID=...", "RGD_DATA TABLE is FULL!", C-887 RGD handlers `0x004ed410,0x004eeeb8,0x004f0b24,0x004f0d8c,0x004f21f8`). LEV3456R section 2 is "levels 5,4 (the router graph)" (`map-tiles.md`, C-046-era description). Grid tile section 1 is road-shape/background display geometry; section 4 is admin/place-name index, "not geometry" (C-280).

## Interpretation

- **FACT:** Navi.exe build A has distinct `MAP_DATA READ` (`fn 0x00425f40`, `0x0017c3ec`) and `RGD_DATA READ` (`fn 0x004266ec`, `0x0017c4ac`) load paths with separate slot tables; both call shared loader/validator `0x0041ee14` → `0x0041ebc0`/`0x0041e7a8`. VAs and call relations verified by `sh4xref.py` and capstone disassembly.
- **OBSERVED:** MAP_DATA is the map display (renderer) data-load path, RGD_DATA is the routing/guide data-load path (string semantics, separate tables, RGD handler cross-ref C-887). LEV3456R section 2 (router graph, levels 5,4) is therefore read by RGD_DATA/router path, not by the renderer/MAP_DATA path. LEV3456R section 1 (coarse geometry, levels 6-3) and grid-tile section 1 (road-shape/background geometry) are display data read by the MAP_DATA/renderer path.
- **OBSERVED (negative, scoped):** Grid tile section 4 (place-name index, `w2=0x0009`, dir kind `0x1146`, section type `0x93`) has no evidence of being read by the MAP_DATA (`0x00425f40`), RGD_DATA (`0x004266ec`), or shared loader `0x0041ee14`/`0x0041ebc0` paths traced (107 functions). No section-4-specific type/dir-kind comparison was found by the searches above.
- **UNKNOWN:** Whether a separate renderer label/place-name subsystem (outside the MAP_DATA/RGD_DATA tile-load call graph traced here) reads section 4 at render time. No such VA was located by this task's methods. Section 4 remains "administrative/place-name index, not geometry" (C-280).
