kernel-context stubs/bypass for `DECOMP_WRAP 0x88037590` (C-2293), calling

EXP-49 sec1 (`psize 0x2c6`, form-1 `ulen 0x484`, `vsize 0x5b8`) and sec2
(`psize 0x68c`, `ulen/vsize 0xcc0`) (C-665 vectors). **Falsifier (for the
decode claim):** the runtime returns a length/bytes different from the M1.2a
expected lengths, or faults in a way attributable to the decompressor (not the
harness). **Falsifier (for this blocked attempt):** a usable `qemu-system-sh4`
(LE) binary exists or can be produced with available deps, allowing the probe
