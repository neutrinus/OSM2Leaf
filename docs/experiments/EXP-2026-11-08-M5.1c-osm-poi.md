## Question

Can the IMF extractor carry the node tags a card needs (POI, address, place) into IMF v1 with the fields the writers need, validated by `imf_check --strict`, with names that survive the UTF-8 to CP1252 rule?

## Hypothesis

The IMF schema already reserves `addr`, `poi` and `name` on node records. The PBF format carries node tags (`Node` keys/vals, `DenseNodes.keys_vals`), but the reader discarded them, and XML node tags were not read either. Decoding the tags and keeping feature nodes should make the synthetic fixture produce identical IMF from XML and PBF, with the counts below.

**Falsifier.** Any of these refutes the claim: (a) the three encodings of the POI fixture differ in bytes; (b) a node without a POI, address or place tag (706, 707, 708) appears; (c) the counts differ from 17 nodes / 5 ways / 1 relation / 3 POIs / 3 addresses / 1 place; (d) `fold_cp1252("Piekarnia Zażółć gęślą jaźń")` is not `Piekarnia Zazólc gesla jazn`; (e) `--strict` passes a file with one of the four defects W007–W010; (f) `mesh_split.py` drops a feature node; (g) the real-extract decoder raises or yields tag strings that are not plausible text.

## Interpretation

- **FACT:** `osm_ingest.py` decodes node tags from XML, plain PBF nodes and DenseNodes `keys_vals`; the synthetic POI fixture produces identical bytes in all three encodings (§2).
- **FACT:** The feature rule keeps 5 of the 8 tagged synthetic nodes, with the counts in §3, and `imf_check` accepts the result (§3).
- **FACT:** `--strict` exits 1 on each of W007–W010 and passes the clean file (§5).
- **FACT:** `mesh_split.py` does not drop feature nodes (§6).
- **OBSERVED:** On the first 2,000,000 nodes of the real extract, about 4.7 % of nodes carry a tag and about 2.7 % are feature nodes; the names decode with Polish letters (§7). This is a partial read, not a region count.
- **HYPOTHESIS:** The writer-side fold (`fold_cp1252`) is the right place for the CP1252 rule. IMF keeps the UTF-8 name, so no information is lost in the extract; whether the firmware's collation or search needs the folded form is untested (writer decision, M5.18).
- **UNKNOWN:** POI category taxonomy (`poi.category` is `key=value` only; `POINT` categories are not mapped), the address join rule for building-way addresses (only nodes are handled), and whether 128 is the right cap for POI names (it is the county/city cap; the facility-name cap is not measured).

## Conclusion

`tools/osm_ingest.py` now emits POI, address and place node records, with `tools/imf_check.py --strict` as the build gate and the W007–W010 warnings for the writer-side defects. The synthetic fixture passes all the checks above. The real-bytes read is partial. The region run and its counts are M5.1b (C-2458, open). `docs/research/intermediate-format.md` documents the node fields, and `docs/research/claims.md` carries C-2450–C-2458.

```python
"""Does mesh_split keep POI-only nodes? Compare counts before and after."""
import json
import os
import subprocess
import sys

REPO = os.getcwd()
SCRATCH = os.environ.get("SCRATCH", "/tmp")
sys.path.insert(0, os.path.join(REPO, "tools"))
import osm_ingest as oi  # noqa: E402

oi.write_osm_xml(os.path.join(SCRATCH, "poi.osm"), tagged=oi.POI_FIXTURE_NODES)
oi.ingest(os.path.join(SCRATCH, "poi.osm"), os.path.join(SCRATCH, "poi.imf.jsonl"),
          source_name="synthetic-poi.osm.pbf")
run = subprocess.run(
    [sys.executable, os.path.join(REPO, "tools", "mesh_split.py"),
     os.path.join(SCRATCH, "poi.imf.jsonl"), "-o", os.path.join(SCRATCH, "poi.split.imf.jsonl")],
    capture_output=True, text=True,
)
print("mesh_split exit", run.returncode, run.stderr.strip()[-300:])


def summary(path: str) -> dict:
    recs = [json.loads(line) for line in open(path, encoding="utf-8")]
    return {
        "nodes": sum(r["type"] == "node" for r in recs),
        "ways": sum(r["type"] == "way" for r in recs),
        "poi": sum("poi" in r for r in recs),
        "addr": sum("addr" in r for r in recs),
        "place": sum(r.get("tags", {}).get("place") is not None for r in recs),
    }


print("before", summary(os.path.join(SCRATCH, "poi.imf.jsonl")))
print("after ", summary(os.path.join(SCRATCH, "poi.split.imf.jsonl")))
```

## B. `smoke_pois.py` (pasted in full; `python3 -I smoke_pois.py 2000000`, run from the repo root)

```python
"""Bounded real-bytes smoke for the M5.1c node-tag decoder (not the region run)."""
import itertools
import os
import sys
from collections import Counter

sys.path.insert(0, os.path.join(os.getcwd(), "tools"))
import osm_ingest as oi  # noqa: E402

PATH = "/home/marek/projekty/leafre-work/osm/dolnoslaskie-latest.osm.pbf"
LIMIT_NODES = int(sys.argv[1]) if len(sys.argv) > 1 else 2_000_000

nodes = 0
tagged = 0
kept_wanted = 0
keys = Counter()
examples = []
for event in itertools.islice(oi.iter_pbf(PATH), 10_000_000):
    if event[0] == "header":
        print("header timestamp", event[1].get("timestamp"), "sequence", event[1].get("sequence"))
        continue
    if event[0] != "node":
        if nodes:
            break  # nodes come first in a Geofabrik extract; stop after them
        continue
    _, osm_id, lat, lon, tags = event
    nodes += 1
    if tags:
        tagged += 1
        keys.update(k for k in tags if k in oi.NODE_TAGS)
    kept = oi._kept_node_tags(tags)
    if oi._node_wanted(kept):
        kept_wanted += 1
        if len(examples) < 6:
            examples.append((osm_id, lat, lon, kept))
    if nodes >= LIMIT_NODES:
        break

print(f"nodes_read {nodes} with_any_tags {tagged} feature_nodes {kept_wanted}")
print("whitelisted key counts", dict(keys.most_common(12)))
for ex in examples:
    print("example", ex)
```
