## Method

- Decompressed `.cmp/.ind` via `tools/cmpind.decode`. Inspected headers/records
  with `struct` (BE). Cross-referenced `tools/ze0-viewer/tools_ze0/{addre_io,
  zcode_io,icode_io,refer_header,frames}.py` and `tools/coord.py`.
- COORD001: parsed header 0x1000 and 14-byte records 0x1010; derived 48-bit
  `M=(level_u32<<16)|pad_u16`; checked one-hot `0x400000000000>>(i-1)` for
  non-last regions and `last.level_u32==guard` on EU+US.
- ZCODE: classified form A (filled header, `nodew>0`, `rec_addr!=0xffffffff`:
  ZCODE018,033) vs form B (sentinel header, 31 files). Verified form-A trie
  base 0x1100/halfword children and record base via `addre_io.unaddr(rec_addr)`
  against ZCODE018 record index 0. Characterized form-B `>HHBBHI` dir entries
  (0x1204) and ladder records; tested single-base resolution hypotheses
  (abs, rel-0x1100, hw-0x1100, unaddr, rel-entry, sector) — no uniform base.
- ICODE001: parsed ISO header `>HH (size_halfwords,country_count)` and
  refer_header slots. Located per-language country-chain roots by finding
  `idx==0,nosub==0,roff<0x100000` chain-start rows (ANDORRA anchor EU, CANADA
  anchor US) and reading 33/2-row chains. Searched refer header/slots and
  0x0000–0x50000 for a raw root-pointer table matching verified roots: none
  found.
- Reproducible tests: `tools/coord_zcode_icode.py --selftest` (synthetic: mask
  formula, pack/unpack, addr/unaddr round-trip including ZCODE018 pair,
  form detect, synthetic ICODE chain root) plus `--verify-*` on real files.

## Raw observations

- COORD001 EU: len 4608, header `(guard=0xf0, count=33, field2=7, field3=0x8000, zero=0)`,
  sentinel all-zero @0x11de. r1–r32 `mask48` == `0x400000000000>>(i-1)` (incl.
  r32 `level=0 pad=0x8000 M=0x8000`); r33 last `M=0xf00000 level=0xf0 == guard`.
- COORD001 US: len 4352, `(guard=0x56, count=11, field2=7, field3=0x8000, 0)`,
  sentinel @0x10aa. r1–r10 one-hot; r11 last `M=0x560000 level=0x56 == guard`.
- ZCODE EU: 33 files. Form A = `ZCODE018` (9792768 B, `nodew_hw=3060594,
  first=60, rec_addr_enc=0xbaf00, rec_size=1748280, cr=12, kw=1`) and
  `ZCODE033` (37130240 B, `nodew_hw=11518848, first=144, rec_addr_enc=0x2bf300,
  rec_size=6589468`). Form B = 31 files (sentinel header, `rec_addr=0xffffffff`).
- ZCODE018 form A: `addre_io.unaddr(0xbaf00)=0x5d7800`; record index 0 @0x5d7800
  = `42830,53372,1712,467,42830,53372,2012,280` (matches). Trie bytes @0x1100
  present (`0000003c…`).
- ZCODE033 form A: `unaddr(0x2bf300)=0x15f9800`.
- ZCODE002/001 form B: `cr=12, kw=1, area` present; 12-byte `>HHBBHI` dir
  entries from 0x1204 (tags digits/letters, terminators); ZCODE002 has 2808
  ladder-like 16B records (BE halfwords, 0xffff padding, trailing 0, e.g.
  `(1,0,0,1,0,65535,65535,0)`-class). Single-constant offset base not resolved
  (abs/rel-0x1100/hw-0x1100/unaddr/rel-entry/sector yield mixed hits).
- ICODE001 EU: 111378432 B, ISO header `(7625 halfwords=15250 B, 33 countries)`;
  slots `(4,(512,60)), (13,(2308,1))`. 7 per-language country-chain roots found

- ICODE001 US: 6071808 B, ISO `(464 hw, 2 countries)`; slots `(4,(512,4)),
  (13,(516,1))`. 2 roots @ `0x1500,0x2e5d00`, 2-row chains (CANADA, UNITED
  STATES / ÉTATS-UNIS). Root-pointer table not found in slots/header/0–0x50000.

## Interpretation

- **COORD001 `level` is a 48-bit region bitmask** (`M=(level_u32<<16)|pad_u16`):
  one-hot `0x400000000000>>(i-1)` per non-last region in order; last region
  carries an aggregate mask whose `level_u32` equals the header `guard`. The
  guard/count/field2=7/field3=0x8000 layout is stable across EU and US. Runtime
  selection semantics of the mask are not proven here (structural decode only).
- **ZCODE offset base (form A, verified):** trie `crec` base `0x1100` with
  halfword child indexing; record base = `addre_io.unaddr(rec_addr_enc@0x1012)`
  (the non-linear sector encoding `(off/0x800)<<8|(off%0x800)/0x100`), 16-byte
  records. Form-A addressing is resolved for ZCODE018/033.
- **ZCODE form B (partly resolved):** a distinct sentinel-header index (31 EU
  files) with 12-byte `>HHBBHI` dir entries and 16-byte area-ladder records; no
  single constant offset base resolves directory `offset` fields uniformly.
  Documented as OBSERVED/unresolved rather than guessed.
- **ICODE001 trie roots (verified):** per-language country-chain root byte
  offsets are the chain starts (7 EU, 2 US), with intra-chain `roff` halfword-
  relative to chain start (consistent with `icode_io`). The pointer table that
  indexes roots by language/slot was not located (slots 4/13 are data frames);
  this is an explicit remaining unknown, not a claim of absence in firmware.
