## Question

Can any `RDSTM001` row field be tied to a road identity (a road number or name),
so that its value can be correlated with the OSM tags of at least five known
roads?

## Hypothesis

Probe, with a falsifier. Hypothesis: one 16-byte-row field (`u16` at offsets
0…14, or the code high byte at `+0xd`) is a per-road identity that resolves to
`LCTBL001` names or catalog codes for most distinct values. Falsifier: a field
that resolves at or below the random-value control, or whose unique-value hit
rate is below 0.50, is not a road identity. The format doc already predicts a
negative for speed, one-way and class (C-885), so the gate is meant to be able
to fail.

## Method

1. **Sample and hash.** The US `RDSTM001.DAT` and `LCTBL001.DAT` above, hashed
   before use. The OSM extract is checked against its Geofabrik MD5 before use.
2. **Commands.**

   ```bash
   python3 tools/osm_ingest.py --selftest
   python3 tools/rdstm_link_gate.py --selftest
   python3 tools/rdstm_link_gate.py \
     /home/marek/projekty/leafre-work/m5.12-us/root-factory/RDSTM001/RDSTM001.DAT \
     /home/marek/projekty/leafre-work/m5.12-us/root-factory/RDSTM001/LCTBL001.DAT \
     --rows 4096
   ```

   The gate tests each candidate `u16` (offsets `0x0`…`0xe`) and the high byte
   of the code word (`0xd`) against `rdstm_schema.lctbl_index`. It uses the
   **unique-value** hit rate (`index_hit_unique`), with a control of 4096
   uniform random values from `random.Random(42)`. Pass needs unique hit
   ≥ 0.50, unique hit minus control ≥ 0.10, ≥ 1024 rows and ≥ 64 distinct
   values.
3. **Controls.** *Positive (selftest):* a field of known catalog codes resolves
   at 1.000. *Negative (selftest):* uniform random `u32` at `+4` resolves at
   0.000 and must fail. *Negative (real run):* the 4096-value random-u16
   control, reported in the table.
4. **Scope.** 4096 rows from `0x1000` to `0x10fff`, the first 64 KiB of the
   table. The 16-byte framing is known to drift at `0x10a0` (C-106, C-884), so
   rows after that point may not be records. The OSM side is **not** scored:
   the gate fails first, and the Done-when needs a row-to-road key that does not
   exist. The LCTBL index has 36 catalog codes and 1016 two-byte name prefixes
   (530,985 names), the same as `rdstm_schema.py join`.
5. **Falsifier.** A field with unique-value hit ≥ 0.50 and at least 0.10 above
   the random control refutes the "no key" reading for that field. The
   occurrence-weighted rate, which the old `join` output reports, is not used:
   see C-903.

## Interpretation

- **FACT (tool, selftest):** `rdstm_link_gate.py` gives 1.000 on a positive
  control and 0.000 on a random-u32 control, so it can separate a resolving
  field from a non-resolving one.
- **OBSERVED (sample):** on the US table, no `u16` field, and no code high byte,
  resolves to `LCTBL001` catalog codes or name prefixes at the unique-value
  level above the random control's 1.5 % by more than 0.10. The unique rates
  are 6–10 %, and they are similar for all nine fields, so no field stands out
  as a road key.
- **OBSERVED:** the occurrence rate (0.63–0.67 for every field) is not
  informative; the same field values repeat (4096 occurrences, 1436–1516
  distinct), and the high rate tracks repetition, not identity (C-903).
- **HYPOTHESIS:** `code` at `+0xc` with low byte `0x00` suggests the code is
  the high byte at `+0xd`; this is a reading of the sample, not a decode. The
  `tail` counter is a candidate row index within a group; not verified.
- **UNKNOWN:** whether the EU sample gives the same result; whether rows after
  `0x10a0` (the framing drift) carry a road key under the per-record directory
  (C-884); whether any OSM-tagged road can be tied to a row by any key.

## Conclusion

The M4.2 Done-when cannot be reached from this file. The gate fails on the
unique-value basis for every candidate field, so there is no row-to-road
identity to correlate with OSM `highway`, `maxspeed` or `oneway`. OSM was
downloaded and verified (C-902), but no correlation was computed, because the
row side has no key. This agrees with C-885 (speed, one-way and class are not
in the twelve TMC fields) and C-900/C-1812 (no segment join). The task is
`blocked`, not refuted: the per-record field directory (C-884) is still
undecoded, and the gate covers only the fixed 16-byte frame. The EU sample is
still needed for a like-for-like check.
