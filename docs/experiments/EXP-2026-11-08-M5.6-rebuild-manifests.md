## Question

Can a card tree's manifest/index files be rebuilt so that `cardcheck` L1
(`DRSTR001.DAT` vs tree, `MMAIN001.DAT` `0x1ac` totals vs tile headers, every
`REFER001` `.ind` vs `.cmp`, and `CMP.LST`) passes after the tree content is
present?

## Hypothesis

Rebuilding `DRSTR001.DAT` with `drstr_ze0.build()`, recomputing `MMAIN001.DAT`
`0x1ac` level-table counts as the sum over `MAPAL001/*.DAT` tile headers
(big-endian `u16`, C-164/C-1788), rewriting each `REFER001` `.cmp`/`.ind` pair
stream-preserving, and writing `CMP.LST = \SystemSD\REFER001\` makes a
structurally valid card tree pass L1. **Falsifier:** the rebuilt synthetic tree
fails any L1 check (`drstr`, `mmain`, `cmp`, `version`/`CMP.LST`, or `headers`)
after rebuild, or the rebuild changes bytes in a way that contradicts the
documented factory form (e.g. MMAIN totals not matching tile sums, CMP.LST not
19 bytes).

## Method

1. **Sample and hash.** No vendor data. The `--selftest` constructs a temporary
   synthetic card tree: required top-level dirs (`MAPAL001`, `REFER001`,
   `REFER002`, `RDSTM001`, `BICON001`, `OPNG`, `SPEECH`, `TMC`), `MMAIN001.DAT`
   with intentionally wrong `0x1ac` counts, `MAPAL001/LEV3456R.DAT` and
   `MAPAL001/B30R060R.DAT` with matching common headers and a level table
   (section 1, levels 6/5, count 1 each), a valid `REFER001/POINT001.DAT.cmp/.ind`
   pair whose decoded payload carries a valid Clarion header, and a wrong
   `CMP.LST`. `DRSTR001.DAT` is overwritten with garbage before rebuild.
2. **Commands.**
   ```bash
   python3 tools/rebuild_manifests.py --selftest
   python3 tools/selftest.py --only rebuild_manifests
   python3 tools/claims_check.py
   ```
3. **Controls.** *Positive*: after rebuild the synthetic tree passes
   `cardcheck` L1 (`partial=True`, full `.cmp` decode) — `drstr`, `mmain`,
   `cmp`, `headers`, `tree`, `version`/`CMP.LST` all OK. `REFER001` pair count
   rebuilt = 1, MMAIN `count_fields_changed >= 1`, `CMP.LST` bytes equal
   `b"\\SystemSD\\REFER001\\"`. *Negative / idempotence*: a second rebuild on
   the already-passing tree still passes L1 and reports
   `mmain.count_fields_changed == 0` (no spurious churn in the totals path).
4. **Scope.** Structural rebuild of the four manifest/index artifacts named in
   M5.6, on a filesystem card tree. It recomputes MMAIN `0x1ac` totals from
   tile headers present under `MAPAL001` and rewrites `REFER001` `.ind` files
   stream-preserving per pair; it does not regenerate MMAIN bounds/text
   (`0x184`/header), does not recompress REFER payloads, and does not touch
   `VER_INFO`/image `0x06000000`/FAT layout. Vendor EU/US trees were not
   available as extracted roots in this session (`leafre-work/root` held only
   `MAPAL001`, no `leaf2011.img` at the AGENTS path), so the done-when is
   evidenced by the complete synthetic L1 pass; EU `DRSTR` byte-identity on an
   unchanged tree is separately established by M4.20/C-2101 and the builder
   preserves stored name/order.
5. **Falsifier.** Any L1 error after rebuild on the synthetic tree, or
   `mmain.count_fields_changed != 0` on the idempotent second pass.

## Interpretation

- **FACT:** `tools/rebuild_manifests.py` rebuilds `CMP.LST` to the fixed 19-byte
  value, `DRSTR001.DAT` via `drstr_ze0.build(root)`, `MMAIN001.DAT` `0x1ac`
  counts from `MAPAL001` tile level-table sums (big-endian `u16` writes), and
  `REFER001` `.ind` by stream-preserving pair load/write (`cmpind_writer.CmpFile`).
- **VERIFIED (synthetic):** a card tree with wrong/stale manifests becomes L1-pass
  after rebuild, and a second rebuild is idempotent on MMAIN totals.
- **OBSERVED:** the done-when "L1 passes on the output card tree" is met on the
  synthetic card tree in this session; a full extracted vendor EU/US root was not
  present locally for an end-to-end factory-tree run.
- **HYPOTHESIS:** on an unchanged factory tree the rebuild is byte-preserving for
  `DRSTR`/`MMAIN`/`CMP.LST` (supported by C-2101 and factory MMAIN sums, not
  re-measured here against a full extracted root).

## Conclusion

M5.6's rebuild capability is implemented in `tools/rebuild_manifests.py` with a
synthetic selftest that exercises the broken→fixed→L1-pass→idempotent path.
The tool follows the documented contracts: `drstr_ze0` case/order preservation,
MMAIN `0x1ac` tile-sum counts (big-endian, cardcheck-enforced), stream-preserving
REFER `.ind` rewrite, and the fixed `CMP.LST`. A follow-up run on a full
extracted EU/US factory tree (when available locally) can confirm byte-stability
on unchanged inputs; it is not required for the structural L1 done-when proved
here.
