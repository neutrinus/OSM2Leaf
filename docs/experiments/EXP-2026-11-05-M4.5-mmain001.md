# EXP-2026-11-05-M4.5: MMAIN001.DAT is a FAT root-directory log

Task: M4.5. Done when: a writer reproduces the 4,096-byte file byte-identically,
with the entry count stated, and every field has a meaning or `UNKNOWN`.

## Method

- Source: the EU 2011 navi158 SD image, partition 0 (FAT32). The root entry
  `MMAIN001.DAT` (size 4096, cluster 2) was read from the root directory.
  Extracted file SHA-256 `fe24bbc82f20bd32633c08086baa3267a5761a6eae4c682f2a20fd668048a5aa`.
  The file stays in the scratchpad, not the repository.
- Parser and writer: `tools/mmain.py`. Each record is kept as its raw fields.

## Observations

- `0x000–0x01f`: label `QSD-309-101` at `0x00`. The other header bytes are
  `UNKNOWN`, kept verbatim.
- `0x020–0x67f`: 51 records of 32 bytes in FAT short-name layout. Layout is
  VERIFIED (name, ext, attr, times, cluster, size all parse as FAT entries).
  39 records start with `0xE5` (deleted). 12 are live.
- `0x680–0xfff`: zero fill.
- Live records (current root listing): `MMAIN001.DAT`, `BICON001`, `MAPAL001`,
  `OPNG`, `RDSTM001`, `REFER001`, `REFER002`, `SPEECH`, `TMC`, `VER_INFO`,
  `CMP.LST`, `DRSTR001.DAT`.
- The file is a log of past root-directory writes, with deleted records kept.
  It is not a manifest of data files.

## Result

- Round-trip: `roundtrip=OK` on the real file, and `selftest: OK` on a
  synthetic file. Writer rebuilds the 4,096 bytes from the parsed fields.
- Entry count: the task text says 11. The file holds 12 live records. The
  twelfth is `DRSTR001.DAT`, which is the same as the `drstr.md` root listing
  plus `DRSTR001.DAT` at `0x660`. Counted as 51 records in total, the log
  holds 39 deleted and 12 live.
- Field meanings: directory record fields are VERIFIED FAT. The header bytes
  beyond the label are UNKNOWN.

## Conflict with docs/format/drstr.md

`drstr.md` places a per-language code list at `0x18c` and a 3-section
descriptor at `0x1ac`. In this file, `0x18c` and `0x1ac` fall inside directory
records (`ER_INFO` at `0x180` and `0x1a0`). The descriptor reading does not
match this layout. Not resolved here.
