# EXP-2026-11-05-M4.6: The B30R048R 2013–2016 rebuild difference

- **Status:** done
- **Date:** 2026-11-05
- **Sample:** ZE0-era extracted card roots
  - `/home/marek/projekty/leafre-work/root` (2011)
  - `/home/marek/projekty/leafre-work/_root2014` (2014)
  - `/home/marek/projekty/leafre-work/_root2016` (2016)
- **Claims:** C-940–C-949
- **Supersedes:** none (relates to C-503, C-504)
- **Superseded by:** none

## Question

Why does `MAPAL001/B30R048R.DAT` fail the byte-identical rebuild at `0x807`/`0x808`
on the 2013–2016 archives, and can the writer reproduce it without the
preserved-layout fallback in `tools/ze0-viewer/ze0_tile_io.py`?

## Hypothesis

Two independent causes:

1. The tile's blocks are stored in a **non-monotonic** layout: one slot's block
   can sit inside an earlier directory's padded range (slot 24 of the level-1
   directory of kind `0x2246` lives at offset `0x6000`, inside slot 16 of the
   level-2 directory). The old sequential pass in `clarion_tile.write_tile`
   assumed offsets were monotonic and disabled preserve mode on the first
   backwards jump, compacting everything after it and changing the section-table
   addresses at `0x807`/`0x808`.

2. `addr_of` is **not injective**: `(offset // 2048) << 8 | (offset % 2048) // 256`
   has many preimages for offsets that are multiples of 2048 (e.g. `0x60` and
   `0xc00` both decode to `0x6000`). The factory sometimes uses a
   non-canonical encoding, so recomputing the tag with `enc_addr` changes bytes.

## Method

```bash
cd tools/ze0-viewer && python3 harness.py verify <root>/MAPAL001/B30R048R.DAT
python3 tools/l2check.py --root <root> --no-golden [--ignore-dump-artifacts]
```

Investigated `tools/ze0-viewer/vendor/osm2clarion/tools/clarion_tile.py`:
`read_tile` (section table, directory pointers) and `write_tile` (preserve pass).

## Observations

- For 2011/2014/2016, `B30R048R.DAT` has identical section counts (3 sections:
  ids 1, 2, 4) and level layouts; only content and offsets differ.
- Slot 24 of the level-1 directory (kind `0x2246`) has `block_off = 0x6000`,
  which lies inside slot 16 of the level-2 directory (`0x5a00..0x6800` padded).
  The two ranges overlap in storage; the factory reuses the shared block.
- The original section-table tag for the first section is `0x00000200`
  (offset `0x1000`), a multiple of 2048, with the non-canonical alternative
  `0x00000010` decoding to the same offset. The factory uses `0x00000200`.
- The original directory pointer for the slot-24 block is `0x00000060`
  (offset `0x6000`), the non-canonical form; `enc_addr(0x6000)` produces
  `0x00000c00`.

## Fix

1. `read_tile` now stores the original section-table tag (`ttag`) and each
   directory's original pointer tag (`ptr_tag`).
2. `dir_bytes` uses the original slot tag when the slot is unchanged
   (`addr == block_off`), so non-canonical encodings survive.
3. `write_tile` gains a random-access preserve path (`_try_preserve_random`)
   that places every component at its original offset instead of a monotonic
   cursor, fills gaps from the source, and reproduces the file byte-identically
   for unchanged tiles. It returns `None` for changed tiles, falling back to the
   compact path.
4. The section-table write uses the original `ttag` when unchanged.

## Result

After the fix:

```
B30R048R.DAT: byte-identical rebuild OK (1358592 bytes)   # 2011
B30R048R.DAT: byte-identical rebuild OK (1526528 bytes)   # 2014
B30R048R.DAT: byte-identical rebuild OK (1551872 bytes)   # 2016
```

`tools/l2check.py` reports `preserved=0` on all three roots (no fallback used).

## Claims

- C-940: B30R048R uses a non-monotonic, shared-block layout; slot 24 of the
  level-1 directory lives at `0x6000` inside slot 16 of the level-2 directory.
- C-941: `addr_of` is non-injective for offsets that are multiples of 2048;
  the factory uses non-canonical tags (`0x60` for `0x6000`).
- C-942: `clarion_tile.write_tile` reproduces B30R048R byte-identically for
  2011/2014/2016 without the preserve fallback.
- C-943: L2 `tile_roundtrip` reports `preserved=0` on all three ZE0 roots.
- C-944–C-949: reserved.
