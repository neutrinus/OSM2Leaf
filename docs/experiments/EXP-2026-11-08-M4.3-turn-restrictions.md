## Question

Can one OSM `restriction=*` at a named junction be found in the extract, decoded,
and written into the connectivity encoding that `docs/format/` describes?

## Hypothesis

The repo has a decoder for `RDSTM001` records (M4.1) and an IMF extractor that
keeps `type=restriction` relations. Hypothesis: the restriction can be decoded to
(via node, from link, to link) and the tile side has a place for it. Falsifier:
no named restriction survives the extract, or the tile-side encoding the docs
describe does not exist, or a factory tile carries no record that the decoded
restriction could be compared with.

## Interpretation

1. The OSM side is done: a named restriction at a named junction is in the
   extract and decodes to an unambiguous `(from way, via node, to way)`
   triple, with the via node at the end of both ways. `r120176` is the case.
2. The tile side is not done, and the docs do not describe it. `RDSTM001` has
   no restriction field (C-885/C-886). The only connectivity-regulation code in
   the repo is the pinned `osm2clarion` writer in `tools_ze0/` (C-914), which
   writes `0xff`-prohibition words. Nothing in `docs/format/` says these words
   exist in a factory tile.
3. The factory evidence is absent or unreadable. On the one walkable tile
   (`B30R060R`) the repo's reader reports zero no-entry and zero barred words, so
   it does not contradict the writer, but it does not show a restriction either.
   Four of five local tiles stop at the reader's kind assertion (C-915).
   The reader's own header-vs-body check is 1/37 on that tile, so its counts are
   not yet trustworthy.
4. Therefore the decode target ("the connectivity encoding the docs describe")
   does not exist. The Done-when is not reached. Per the TODO rule, the status is
   `blocked`, not `done`.

**Missing piece:** a `docs/format/` page for the section-2 connectivity and
regulation records, backed by a reader for section-2 directory kinds `0x2046`
and `0x3e4`, and one factory tile where a known OSM restriction (for example
`r120176`) can be matched to a regulation word. Until then, the writer's
`PROHIBITED = 0xff` encoding is a hypothesis (M), not a format fact.
