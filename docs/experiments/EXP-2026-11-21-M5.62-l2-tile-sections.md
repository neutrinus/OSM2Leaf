- **Status:** done
- **Date:** 2026-11-21
- **Sample:** synthetic (no vendor data) — a `one_tile_pipeline.py --synthetic`
  `B48R058R.DAT` (37,376 B, SHA-256
  `f50f59e9ba441646ac1f7aa547342c88059f17ee1c557d30dbeba34b7205c12f`), a copy
  with its third section-list entry blanked (SHA-256

  EU 2011 factory tile `B28R070R.DAT` (SHA-256

  real factory file used only as the INFO positive control)
- **Tools:** Python 3.15.0 / zlib 1.3.1.zlib-ng (no recompression is done;

  `tools/one_tile_pipeline.py`, `tools/tilewriter.py`,
  `tools/tile_drop_l3.py`
- **Claims:** C-6510–C-6519 (the next free ten-block: C-6500–C-6509 is

## Question

Can L2 refuse a generated `BxxRyyyR.DAT` whose section list at header `0x800`
has fewer than three entries — the tile the firmware leaves on the first mount
(C-6080–C-6083) — without failing a factory tile that legitimately holds fewer
(8 of 45 on EU 2011, C-6085)?

## Hypothesis

Exploratory. Expectation from C-6087: the fresh `tilewriter.py` container
lists three sections, so a rule that a **named generated** tile must list
three entries passes every generated tile today and fails only a writer
regression that drops an empty section. A factory tile copied verbatim must
not fail (C-6085), so the rule needs a provenance escape.

**Falsifier:** a generated tile with three entries is refused; or a generated
tile whose third entry is blanked passes; or a factory tile kept verbatim
(identical to its `--factory-root` file) is refused.

## Method

1. **Sample and hash.** The synthetic tree is produced by
   `one_tile_pipeline.py --synthetic` (its `--json` prints `tile_sha256`,
   quoted below); the blanked copy is that tile with
   `0x80c..0x811 = ff ff ff ff 00 00`; the factory control is the EU 2011
   `B28R070R.DAT` (2 entries). No vendor bytes are committed.
2. **Commands.** Run from the repo root; `$S` is
   `~/projekty/leafre-work/scratch/m562`.

   ```bash
   S=~/projekty/leafre-work/scratch/m562
   FAC=/home/marek/projekty/leafre-work/m5.29-factory-root

   # the sample: a generated tile with three sections
   python3 tools/one_tile_pipeline.py --synthetic --out "$S/synth" \
     --cell B48R058R --json "$S/synth.json"            # rc 0
   sha256sum "$S/synth/MAPAL001/B48R058R.DAT"           # f50f59e9…

   # a copy with the third entry blanked
   cp -a "$S/synth" "$S/synth-blank"
   python3 - <<'PY'
   from pathlib import Path
   p = Path("/home/marek/projekty/leafre-work/scratch/m562/synth-blank/MAPAL001/B48R058R.DAT")
   raw = bytearray(p.read_bytes())
   raw[0x80c:0x812] = b"\xff\xff\xff\xff\x00\x00"
   p.write_bytes(bytes(raw))
   PY
   sha256sum "$S/synth-blank/MAPAL001/B48R058R.DAT"     # b85e3c48…

   # the passing case: the unchanged generated tile
   python3 tools/l2check.py --root "$S/synth" --partial --no-golden --no-cmp \
     --tiles B48R058R.DAT                               # exit 0
   # the failing case: the blanked third entry
   python3 tools/l2check.py --root "$S/synth-blank" --partial --no-golden \
     --no-cmp --tiles B48R058R.DAT                      # exit 1

   # INFO control: the real factory short tile, identical to --factory-root
   python3 tools/l2check.py --root "$S/facverb" --partial --no-golden \
     --no-cmp --tiles B28R070R.DAT --factory-root "$FAC"  # exit 0
   # negative control: the same factory tile, no --factory-root
   python3 tools/l2check.py --root "$S/facverb" --partial --no-golden \
     --no-cmp --tiles B28R070R.DAT                        # exit 1
   # the raw factory card on the default list (INFO, must not fail)
   python3 tools/l2check.py --root /home/marek/projekty/leafre-work/m5.4/card-factory \
     --no-golden --cmp-limit 5 --skip-mutation            # exit 0

   python3 tools/l2check.py --selftest                   # 26 checks, PASS
   python3 tools/selftest.py --only l2check              # PASS
   ```

3. **Controls.** *Positive:* the factory `B28R070R.DAT` (2 entries) reached
   with `--factory-root` prints `factory bytes kept verbatim (INFO…)` and the
   run is `PASS`; the synthetic tree with a full list prints
   `[tile_section_list] OK`. *Negative:* the blanked copy (`B48R058R.DAT=2`)
   fails with the `0x80c` message; the same factory file without
   `--factory-root` fails (`factory_verbatim=0`); a short list that differs
   from the factory by one byte still fails (selftest).
4. **Scope.** `tools/l2check.py` only: one `cardcheck.Check("tile_section_list")`
   and its selftest. The rule covers `BxxRyyyR.DAT`; `LEV3456R.DAT` lists two
   by design and is excluded (C-6085). It reads bytes `0x800..0x811` via
   `tile_drop_l3.parse_section_list` and does not decode the tile body. The
   EU 2011 factory census (37/7/1 by entries, C-6085) is not re-derived here.
5. **Falsifier.** As stated above; it did not fire (the generated tile passes,
   the blanked tile fails, the verbatim factory tile passes).

## Interpretation

- **FACT:** the rule fails a named generated `BxxRyyyR.DAT` whose section list
  at `0x800` has fewer than three entries, and names the first missing entry
  (`0x80c` for a two-entry list, `0x806, 0x80c` for a one-entry list).
- **FACT:** a tile byte-identical to the run's `--factory-root` MAPAL001 file,
  and a short tile reached only by the default list, are INFO, not failures;
  the raw EU 2011 factory card stays `RESULT: PASS` (C-6085's three short
  tiles are the INFO rows).
- **OBSERVED:** the current `tilewriter.py` container already lists three
  sections (C-6087); `one_tile_pipeline.py --synthetic` passes the new rule
  unchanged.
- **HYPOTHESIS:** a future writer that drops an empty section is caught here
  before the card reaches the unit, where C-6080–C-6083 say the tile is left
  and the mount moves to box 0.
- **UNKNOWN:** acceptance on the unit (L3/L4/L5); this is an offline L2 gate,
  rule 13.

## Conclusion

`tools/l2check.py` gains `tile_section_list` (M5.62): every `BxxRyyyR.DAT`
named on `--tiles`/`--semantic-tiles`/`--class-tiles` must list three sections
at header `0x800`/`0x806`/`0x80c`, none `ff ff ff ff`; a factory tile kept
verbatim (`--factory-root`, new flag) and an unnamed default-list tile are
INFO. The selftest holds the three-entry pass, the blanked-third-entry fail,
the default-list INFO, the factory-verbatim INFO and the
differs-from-factory fail. `docs/format/map-tiles.md` already states the rule
(M3.33, C-6087); this is the L2 enforcement. Claims C-6510–C-6519.
