## Question

What are the six words at common-header `0x180`, the per-language code list
that the TODO places at `DRSTR001` `0x18c`, and `BICON001`'s data version
`11/04/08/01`? Do the `0x18c` codes match the `SPEECH/` language sets?

## Hypothesis

Pre-registered before the run.

- **H1.** Words 2–5 of `0x180` (`0x184`–`0x18b`) are four big-endian i16 bounds
  that contain every `MAPAL001` tile. **Falsifier:** any tile outside the box on
  any image, or bounds that differ between images without a matching tile change.
- **H2.** The TODO's `DRSTR001` `0x18c` is a mis-attribution, because
  `DRSTR001.DAT` has no common header. **Falsifier:** the node table at `0x18c`
  does not parse as 40-byte nodes on all four images.
- **H3.** The `0x18c` list is a language code list whose length equals the number
  of `SPEECH/<lang>` sets. **Falsifier:** a count mismatch beyond one extra code,
  or sets that are not nested across years, or no code-to-name anchor (then the
  identity part stays `UNKNOWN`).
- **H4.** `BICON001`'s `DATA VERSION` differs from the other map files on every
  image. **Falsifier:** any image where `BICON001` carries the same stamp as
  `MMAIN001`, `MAPAL001`, `RDSTM001` and `LCTBL001`.

## Interpretation

- **FACT (VERIFIED):** the `0x180` prefix is `ff ff ?? ff 12 c0` on all eight real
  headers; byte `0x182` is `24` on EU and `26` on US. The `0x184`–`0x18b` words
  are four big-endian i16 values. Every tile lies inside the header box, and the
  US box matches the US tile set exactly in longitude. `0x18c` in DRSTR001 is a
  node `listing_offset`, not a language list. The `SPEECH` node's entry count
  equals the number of `SPEECH/<lang>` dirs on all four images. `BICON001`'s
  stamp differs from `MMAIN001` on EU 2011 and US 2011 only.
- **OBSERVED:** the N, S, W, E reading of the bounds (the order is a reading, not
  a proof); the EU east bound (68°) extends past the tile set (36°), so it is a
  database extent rather than a tile edge; the `0x18c` code count is 8 and 17 on
  EU and 2 on US, with the EU 2011 codes a subset of EU 2014's; the nine codes
  added in 2014 match the nine languages added in 2014 by count.
- **HYPOTHESIS:** `DATA VERSION YY/MM/DD/NN` is a per-file build-date label. It is
  not the FAT modification time (EU 2014 MMAIN001 is stamped `14/04/12` and
  modified `2014-03-13`), and the firmware does not compare it (drstr.md, M3.8).
  Two readings fit the code counts: `0x14` is an EU-only non-speech code, or `04`
  is English (speech on US, text-only on EU). The four images do not separate
  them.
- **UNKNOWN:** the meaning of `0x180`–`0x183` (`ffff`, and `ff24`/`ff26`); the
  identity of each `0x18c` code and therefore the `SPEECH/` set it selects; whether
  any reader consumes the `BICON001` stamp.
