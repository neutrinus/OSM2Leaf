- **Date:** 2026-11-23

## Question

Which data and code give the Leaf's route options (fast / eco / short,
motorways, ferries), and which link words do they act on?

## Hypothesis

The link cost function `0x00341980` reads per-class tables that a setup
function fills from the search request; each route type selects a different
table. Falsifier: the tables do not depend on the request, or all three
plural searches use the same table.

## Method

1. Decompile `0x00341980` (link cost) and list every function whose literal
   pool holds the cost tables (`0x01200d90`…`0x01201020`, `0x0061fad8`,
   `0x0061fb18`): the writer is `0x00341134`, called through a pointer from
   `0x00367e38`.
2. Read the three static profiles at `0x0055f218` (`3 × 0x160` bytes = 16
   classes × 11 `w1 >> 12` indices × u16) from the decompressed `.data`.
3. L4: factory card, NK1 + unit flash, route recipe of M9.75; gdb breakpoint
   at `0x00341134`, print `r4 + 0xb4` and `r4 + 0xb8` at each hit.
4. Ferry classes: place the class-10 and class-11 links of `B48R068R` level 1
   on the map (parcel code → lat/lon via `clarion_bg.parcel_geo`).

## Observations

- `0x00341980`: cost = `table[class][w1 >> 12]` (table pointer per class
  from `0x0061fad8`; `w1 & 0x30 == 0x30` uses a separate row) times a length
  term, minus a per-attribute term (`0x0061fb18`), plus penalties for
  `(w1 & 0xe00) == 0x400`, `(w1 & 0x1c0) == 0x140` (×1.75), `w0 & 0x4000`,
  a class change between consecutive links and a turn table; classes 10 and
  11 skip the length term (fixed cost per crossing).
- `0x00341134` copies one of three profiles by request word `+0xb8`: 4 →
  profile 2, 6 → profile 1, anything else (5) → profile 0; it also copies
  smaller tables indexed by `(+0xb4 >> 2) & 3` and `(+0xb4 >> 12) & 3`.
- Profiles, row = class, value per `w1 >> 12` index 0…10 (excerpt):

  | Class | Profile 0 | Profile 1 | Profile 2 |
  | --- | --- | --- | --- |
  | 0–2 (motorway) | 50 50 74 70 … | 195 195 350 200 … | 10 10 11 11 15 … |
  | 3–4 | 50 55 60 70 … | 50 60 60 70 … | same as above |
  | 5 | 55 55 60 70 … | 55 55 60 70 … | same |
  | 7 | 60 60 80 60 90 … | 65 60 80 60 90 … | same |
  | 8 | 105 100 100 110 120 … | 100 100 100 110 120 … | same |
  | 9 | 120 110 110 110 130 … | 110 110 110 120 130 … | same |
  | 10, 11 (ferry) | 7 10 …, 9 10 … | 8 10 …, 9 10 … | 8 10 10 12 …, 11 10 10 12 … |
  | 12 | 10 … | 1 … | 1 … |

  Profile 0 is time-like (minor roads cost twice a motorway), profile 1
  makes motorways about four times dearer, profile 2 is nearly flat
  (distance).
- L4 (one New Destination, start `a6a0cde3` 1395,980): the breakpoint fires
  for PLURAL 1/3, 2/3 and 3/3 with `+0xb8` = 5, 6, 4 in that order and
  `+0xb4 = 0x5624` each time. So the three routes the unit offers are
  profile 0, 1 and 2; with the UI's first route labelled "Fast", 5 = fast,
  6 = the motorway-avoiding eco route, and 4 = short (reading of the
  labels, not checked button by button).
- Ferries: class 11 links sit at 50.915 N 1.799 E (Coquelles, the Channel
  Tunnel car shuttle terminal) and 51.570 N 2.985 W (Newport, the
  transporter bridge); class 10 at 48.642 N 2.031 W (Saint-Malo / Dinard).
  Both classes have `w1 >> 12 = 0` on every end (5,478 and 108 ends).
- Section-2 level 2 of `B48R068R` holds classes 1–7 plus the ferry classes
  (1,060,975 link ends; class 8/9 only 168 + 182); levels 4 and 5 are empty in
  the grid tile, so they live in `LEV3456R.DAT`.

- Owner's manual (2011 LEAF navigation manual, Marek's copy, not
  committed):
  - [More Routes] offers Short. Time (purple), Min. Freeway (orange) and
    Short. Dist (green). This is the L4 order of `+0xb8` = 5, 6, 4, so
    profile 0 = shortest time, profile 1 = minimise freeways and profile 2 =
    shortest distance.
  - The default comes from MENU → Route → Route Settings → Basic Route Type
    (Fastest / Minimize Freeway / Shortest).
  - The switches are under MENU → Route → Route Settings → Other Routing
    Choices: Minimize Toll Roads, Use Time Restricted Roads, Use Real Time
    Traffic Information, Use Avoid Area Settings, Use Ferries, Auto Reroute.
  - Avoid Areas (up to 10) are under Address Book → Avoid Area.
  - `tools/panel.py` has the MENU key (`key MENU`, vk `0x18`), so these
    screens can be reached in the emulator.

## Interpretation

A writer must give `w1 >> 12` the factory's value per road type (it selects
the cost column) and must put ferries and shuttle trains in class 10/11;
then all three route types behave as in the factory. Avoid-motorway, toll
and ferry switches in the settings are not the profile selector: the
request word `+0xb4` and the other request fields are the next place to
look, by changing each setting in the UI and diffing the request.

## Conclusion

Three route types = three static cost profiles selected by the request word
`+0xb8` (5, 6, 4). The settings switches are open.

`0x341134` and a memory read of `r4 + 0xa0`, 0x30 bytes.
