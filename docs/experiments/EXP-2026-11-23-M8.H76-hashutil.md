## Question

Can the 26 private SHA-256 helper definitions under `tools/` be replaced by
one `tools/hashutil.py` (`sha256_file(path, chunk=1<<20)`, `sha256_bytes(data)`)
without changing the hex any call site computes?

## Hypothesis

Yes. The measured differences between the copies are chunk size (`1 << 16`,
`1 << 20`, `8 << 20`, `COPY_CHUNK`, `1024*1024`) and whether the argument is a
path or a byte string. SHA-256 of a file is chunk-invariant, so aliasing each
local name to the matching shared helper keeps every digest identical. The one
copy whose second argument is a **byte limit** (`fn_match.py`) cannot line up
with `chunk=`; per the task's Stop rule it keeps a distinct name.

**Falsifier:** after the change, two call sites return different hex for the
same named file, the full-file hash differs from the pre-change hash, or a
`tools/selftest.py` suite that passed at baseline starts to fail.

## Interpretation

- **FACT:** one `tools/hashutil.py` now supplies both helpers; `26` matching
  `def` lines are gone and the Done-when grep is empty (O1).
- **FACT:** every call site's digest is byte-identical (O2), including the
  `fn_match.py` prefix path (O3). The different historical chunk sizes never
  affected the hex string, as expected.
- **OBSERVED:** the suite count rose from `254` to `256` passes because main
  added one new tool suite and this task added `tool:hashutil` (O4).
- **OBSERVED:** the plain `/tmp` selftest run is red on this host for a disk
  quota reason unrelated to this change; the green baseline was measured with
  `TMPDIR` in the home tree (O5).
- **HYPOTHESIS:** none.
- **UNKNOWN:** whether any non-matching hash helper elsewhere in the repo is
  also a copy; it was outside the task's regex (Scope).

## Conclusion

No format document changes. `tools/hashutil.py` is the single implementation
of `sha256_file` and `sha256_bytes`; the `25` former owners now alias it, except
`fn_match.py`, whose byte-limit helper is named `sha256_prefix` and delegates
its full-file branch to `hashutil.sha256_file`. All measured digests and suite
results stayed green. Three claim rows (C-8530–C-8532) record the elimination,
the byte-identical digests and the prefix exception.
