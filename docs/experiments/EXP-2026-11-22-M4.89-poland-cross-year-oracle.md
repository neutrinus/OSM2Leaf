## Question

Decodes the factory EU2014 Poland map data with the **2011** offline decoders,
and does it expose a factory-made answer sheet (Polish names, the LCTBL
country/table code for Poland, road/POI classes) the compiler can target?

## Hypothesis

The ZE0-era container and record grammars are unchanged from 2011 to 2014
(C-120, EXP-2026-11-19-M4.41), so each 2011 decoder reads the EU2014 Poland
files with the same framing and reports strictly more Polish detail. The
**falsifier** set before the result: if the four Poland tiles have the same
sizes and the same record counts in EU2011 and EU2014, the 2014 card is not a
richer oracle and the hypothesis fails. A second falsifier: any family whose
2011 decoder refuses the 2014 bytes is reported as `different format`, not
repaired or converted.

2. **Commands.** Runnable as written from the worktree root; `S` as above.

   # prechecks and inputs already known before the study
   python3 tools/fetch_image.py --verify archive/sd-images/LEAF_2014_EU_QSD-357-101.img

3. **Controls.** *Positive:* the 2011 decoder on the 2011 sample reproduces
   its documented totals (`lctbl_records.py verify` -> documented stream and
   record counts; `point_census.py census` -> `VERDICT: every byte reached`).
   *Negative:* the same `diff_years_tiles.py` census with EU2014 on **both**
   sides must print `identical=4` and `added=0 removed=0 changed=0` in every
   section (a change-detector that fires on unchanged bytes is not a result);
   a US2011 file given to the EU2014 LCTBL parser must fail or report a
   different format. *Falsifier control:* the four tile sizes must grow; equal
   sizes and equal record counts refute the "richer oracle" hypothesis.

4. **Scope.** Four Poland tiles × 2 cards, one LCTBL file per card, one POINT
   shard per card, plus the whole-card tree/container census for 2011/2014.
   Excluded: the 2019 QY8x engine (different family), the full EU tile set
   beyond the four Poland tiles, US2011 except as negative control, and all
   firmware/L3 work. Files are read from the images into scratch only; no
   `.DAT`, `.cmp`, `.ind` or image is written to the repo.

5. **Falsifier.** Same Poland tile sizes and same record counts on both cards;
   a family whose 2011 decoder refuses the 2014 bytes; or an LCTBL table code
   that cannot be quoted from a command. Each is reported as observed rather
   than converted into a passing verdict.
