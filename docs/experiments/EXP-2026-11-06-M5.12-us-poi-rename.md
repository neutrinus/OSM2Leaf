# EXP-2026-11-06-M5.12: Rename a POI on the US card image

## Summary

One POI name in the US (N-America) 2011 Leaf ZE0 card image was changed to a
clearly different ASCII string, the REFER001 pair re-packed, the full card image
rebuilt from the mutated tree, and offline checks passed (cmpind verify, L2
structural/cmp checks feasible on US data, `cardcheck.py --image` PASS).

- **Status:** done (offline); hardware pending
- **Date:** 2026-11-06
- **Input image (US 2011, Marek's unit market):**
  - URL: `https://files.viaaq.eu/sd-images/LEAF_2011-2012_US.img`
  - size: 8,057,257,984 bytes
  - SHA-256: `53342430a1bb58d3ed6eb68c5563f079c710a400134d522e6192489b324c5383`
  - map code/version label observed by cardcheck on factory image:
    `QSD-301-103` (FAT label) / 113 tiles (mmain), 248 files, 58 cmp pairs
- **Changed POI (documented for on-unit confirmation):**
  - file: `REFER001/POINT010.DAT.cmp` / `.ind` (logical `POINT010.DAT`)
  - inner zlib page (decoded DAT offset): `0x840ba0`
  - page slot: `0x840ba0`–`0x84b300` (42848 bytes)
  - record page: 1000 records (`tag,len2` chain, `0x60/0x68`)
  - record: index 0 at page offset `0x0000`, `tag=0x60`, `len2=64`, total 128
  - **original name:** `HANA HEALTH CENTER` (18 bytes, ASCII)
  - **new name:** `OSM2LEAF TEST POI1` (18 bytes, ASCII, same length)

- **Supersedes:** none (builds on M4.7 rename path)
- **Superseded by:** none

## Method

```bash
# 1. image present and verified (precondition)
sha256sum /home/marek/projekty/leafre-work/m5.12-us/LEAF_2011-2012_US.img
# 53342430a1bb58d3ed6eb68c5563f079c710a400134d522e6192489b324c5383

# 2. factory root extracted (precondition in this session)
# /home/marek/projekty/leafre-work/m5.12-us/root-factory/

# 3. mutated copy
cp -a root-factory root_mut

# 4. candidate found in US REFER001/POINT010.DAT.cmp, page 0x840ba0:
#    "HANA HEALTH CENTER" occurs once in a 1000-record 0x60/0x68 page
#    (record 0, offset 0x0, len2=64, total=128).

# 5. same-length rename (keeps record framing unchanged)
python3 tools/mutate_refer_poi.py \
  root_mut/REFER001/POINT010.DAT.cmp root_mut/REFER001/POINT010.DAT.ind \
  /tmp/opencode/m5.12-poi-out4 \
  --page 0x840ba0 --old "HANA HEALTH CENTER" --new "OSM2LEAF TEST POI1"
cp /tmp/opencode/m5.12-poi-out4/POINT010.DAT.{cmp,ind} root_mut/REFER001/

# 6. mutation validation
python3 tools/validate_mutation.py \
  root-factory/REFER001 root_mut/REFER001 POINT010.DAT \
  --page 0x840ba0 --page-len 42848 --inner-page 0x840ba0 \
  --drstr root_mut/DRSTR001.DAT --drstr-dir REFER001

# 7. cmp/ind integrity
python3 tools/cmpind.py verify root_mut/REFER001

# 8. L2 (US data, EU fixtures/golden not applicable)
TMPDIR=/home/marek/projekty/leafre-work/tmp python3 tools/l2check.py \
  --root root_mut --no-golden --skip-mutation --ignore-dump-artifacts --no-tiles

# 9. rebuild image and cardcheck
python3 tools/mkcard.py \
  --from-image .../LEAF_2011-2012_US.img --tree root_mut \
  -o .../us_m5.12_renamed.img
python3 tools/cardcheck.py --image .../us_m5.12_renamed.img
```

## Observations

### Mutation (`mutate_refer_poi.py`)
```text

inner page recompressed: 42534 bytes (was 42641, L9), 314 bytes spare
outer .cmp 4240574 -> 4233336 bytes, 149 chunk(s)
logical size unchanged: 9715200 bytes
```
The L9 fallback was required because L6 recompression of this 130KB plain page
exceeded the original slot; decompressed content is unchanged except the name.

  (e.g. `POINT010.DAT.cmp`) so rebuilt images preserve correct long filenames.
  Selftest `OK`.
