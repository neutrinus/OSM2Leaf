## Question

Which KIWI-W specification editions are publicly reachable, what chapters does
each contain, and do the chapter numbers quoted by `jharg/kiwiread`
(`1.2.x`, `6.1.x`, `7.2–7.4`) match one of them or JIS D 0810:2004?

## Hypothesis

The `kiwiread` author worked from the consortium's own English edition
(numbered `1`–`15`, `30`, `32`–`34`), not from JIS D 0810:2004, because the code
comments use `1.2.13`, `6.1.1`, `6.2.1`, `7.2` style numbers.

**Falsifier:** the chapter numbers quoted by `kiwiread.c` match no public
document (the author worked from an unpublished edition), **or** they match
JIS D 0810:2004 clause numbers instead of the consortium edition.

## Method

A spec, not a narrative:

1. **Sample and hash.** The four KIWI chapter PDFs and the two ISO/JIS items
   above; no vendor data. Hashes are printed by `sha256sum` in part 2 and must
   match the table.
2. **Commands.** Runnable as written. Wayback `if_` returns the archived bytes
   unmodified; a bare Wayback URL can inject a banner and change the hash.

   ```bash
   mkdir -p ~/projekty/leafre-work/scratch/m4.65/pdf
   cd ~/projekty/leafre-work/scratch/m4.65
   git clone --depth 1 https://github.com/jharg/kiwiread
   git -C kiwiread rev-parse HEAD        # expect 74741c5b75695b7004cc1dea9a9348eab2a511e0

   B=https://web.archive.org/web
   P=http://www.kiwi-w.org/format_english/pdf
   curl -sSL "$B/20150723090830if_/$P/0100122e.pdf" -o pdf/0100122e.pdf
   curl -sSL "$B/20151009143254if_/$P/0500122e.pdf" -o pdf/0500122e.pdf
   curl -sSL "$B/20151009154524if_/$P/0600122e.pdf" -o pdf/0600122e.pdf
   curl -sSL "$B/20151010144459if_/$P/1000122e.pdf" -o pdf/1000122e.pdf
   sha256sum pdf/*.pdf

   curl -sSL -A 'Mozilla/5.0' https://kikakurui.com/d0/D0810-2004-01.html \
        -o kikakurui-D0810-2004.html
   curl -sSL -A 'Mozilla/5.0' \
        https://www.normsplash.com/Samples/ISO/139386839/ISO-TS-20452-2007-en.pdf \
        -o iso-ts-20452-sample.pdf
   sha256sum kikakurui-D0810-2004.html iso-ts-20452-sample.pdf

   # Chapter tags in kiwiread.c (the numbers the tool must find in the PDFs)
   grep -n -E '[0-9]\.[0-9]' kiwiread/kiwiread.c

   # Committed checker: token=TITLE, exit 0 only if every pair matches
   T=~/projekty/OSM2Leaf.task-m4.65-kiwi-sources/tools/kiwi_spec_tokens.py
   python3 "$T" --selftest
   python3 "$T" pdf/0100122e.pdf \
       "1.2.7=Sector Address Type" "1.2.13=Parcel ID Number Type" \
       "1.2.14=Manufacturer Identification Type"
   python3 "$T" pdf/0500122e.pdf \
       "5.1=Data Volume" "5.1.1=Level Management Information"
   python3 "$T" pdf/0600122e.pdf \
       "6.1=Parcel Data Management Distribution Header" \
       "6.1.1=Level Management Record" \
       "6.1.2=Block Set Management Record" "6.2.1=Block Management Record"
   python3 "$T" pdf/1000122e.pdf \
       "10.1=Route Planning Distribution Header" "10.6=Node Data Frame" \
       "10.7=Link Data Frame" "10.10=Link Cost Data Frame" \
       "10.12=Node Coordinate Data Frame"
   ```

3. **Controls.**
   - **Positive control:** `tools/kiwi_spec_tokens.py --selftest` builds a
     synthetic PDF and shows a token+title is found, while a wrong token, a
     prefix token (`6.1` vs `6.1.2`) and an absent title all fail (6/6 in the
     output below). On the real PDFs the same check finds every `kiwiread` tag
     at the same title.
   - **Negative control:** JIS D 0810:2004 puts the same material at different
     clause numbers (`8.1` data types, `9.1` data volume, `10` parcel
     management, `11.x` main map, `14` route planning). If the numbers matched
     both editions the two-edition claim would be unfalsifiable; they do not.
   - **Negative source (claimed but unreachable):** the consortium live path
     `format_kihon.html` (live 404, plain `http:` 401), the chapter-7 PDFs
     (`no Wayback capture`, direct 404), Denso's own KIWI article (Akamai 403)
     and the Wu & Li ICC 2005 poster (connection reset) must all fail — they do
     (Observations). A "looked here, failed" line is the result for those.
4. **Scope.** Four of the consortium's chapter PDFs (1, 5, 6, 10) downloaded
   and hashed; the full chapter *list* read from the archived `menu.html` +
   `menu007/008/011.html`. JIS D 0810 read as a table of contents only (full
   PDF sold). ISO/TS 20452 read as an 8-page preview. Not covered: any chapter
   PDF absent from the Wayback CDX; the sold full JIS/ISO texts; the Denso and
   Wu full texts.
5. **Falsifier.** Stated in Hypothesis before the result: no public document
   carries the numbers, or the numbers belong to JIS clauses.

## Interpretation

- **FACT:** The English KIWI **V1.22** chapter PDFs are publicly reachable in
  the Wayback Machine, dated **30 May 2000**, and carry the chapter numbers
  `1.2.7/1.2.13/1.2.14`, `5.1/5.1.1`, `6.1/6.1.1/6.1.2/6.2.1`, `10.x` with the
  exact titles `kiwiread` quotes. The positive control passed for every number
  checked (chapters 1, 5, 6, 10).
- **FACT:** **JIS D 0810:2004** adopts the same format but **renumbers** the
  clauses (`8.1`, `9.1`, `10`, `11.x`, `14`). A citation using `kiwiread`'s
  numbers is therefore a citation of the consortium edition, not of JIS.
- **FACT:** **ISO/TS 20452:2007** exists and is the ISO *requirements + logical
  data model* specification; its 8-page preview exposes no byte layouts.
- **OBSERVED:** The consortium's live site no longer serves the spec (404/401);
  only the Wayback copies remain. The current site says KIWI 1.22 was approved
  as a JIS standard in March 2004 and the guideline is member-only.
- **OBSERVED (negative):** Denso's own KIWI article and the Wu & Li ICC 2005
  poster were not retrievable (403 / reset); chapter 7 has no archived PDF.
  These are recorded gaps; the conclusion rests on chapters 1/5/6/10 alone.
- **HYPOTHESIS:** `kiwiread` was written from the consortium V1.22 text (or an
  identical reprint); the tags are too specific to come from JIS numbering.
- **UNKNOWN:** Whether a free full text of JIS D 0810 or ISO/TS 20452 exists
  outside paid channels; none was found.

## Conclusion

Public KIWI specification documents exist and are reachable: the consortium's
English **V1.22** chapter PDFs in the Wayback Machine, the **JIS D 0810:2004**
table of contents (sold in full), and an **ISO/TS 20452:2007** preview. The
chapter numbers `kiwiread.c` uses (`1.2.x`, `5.1`, `6.1.x`, `6.2.1`,
`7.2–7.4`) match **KIWI V1.22 exactly** and **JIS D 0810:2004 not at all**
(JIS renumbers them to `8.1`, `9.1`, `10`, `11.x`). The falsifier did not fire.
The inventory is in [`docs/research/kiwi-sources.md`](../research/kiwi-sources.md);
`docs/research/sources.md` links it. Chapter **10 (Route Planning Data Frame)**,
which M4.72 marked *missing*, is now available by name (node, link, regulation,
between-links cost, link cost, upper-level node/link correspondence, node
coordinates, road reference table) as a concept index for M4.40/M5.57 — but
nothing here shows the ZE0 route data uses it (rule 13 unchanged). Scratch
`~/projekty/leafre-work/scratch/m4.65/` was deleted after this record.
