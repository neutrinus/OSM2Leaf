## Question

For SCIF 0–8 in `serial_scif.dll`, what is the receive mechanism (FRDR-triggered
HPB-DMAC channel vs polled IRQ), which DMA channel and interrupt serves each
port, and what must an emulator raise for RX to reach the driver?

## Hypothesis

All configured receive channels use an HPB-DMAC channel armed from the SCIF
FRDR (`SCIFn+0x14`), notified by the channel's completion interrupt; the
mechanism is selected by the register literal passed to a shared dispatcher,
not by a per-channel configuration flag. **Falsifier (from the task):** two
channels of the same driver instance use different mechanisms with no
configuration value selecting them.

### 3. Controls

- **Positive:** `cerom.py modules` prints module 62 `serial_scif.dll` load
  `0x88673000` vbase `0x03980000`; `exports` lists 10 `SCI_*` entrypoints;
  `ze0_serial.py refs` prints the 16 SCIF base/FRDR/FTDR pool words including
  FRDR `0xffe41014` (ch1), `0xffe43014` (ch3), `0xffe47014` (ch7),
  `0xffe48014` (ch8); C2a O1's DSAR=FRDR for ch1/3/7 reproduces (buffer
  addresses `0xa999a800`/`0xa999c800`/`0xa999e800`).
- **Negative / mutation (MANDATORY):** feed the tool a wrong register literal.
  `tools/scif_rx_map.py --selftest` includes the check
  `_classify(0xffe41010) != (1, "FRDR")`; to see it fail loudly, mutating that
  constant to `0xffe41014` makes the check report:
  `FAIL: +0x10 is not misread as FRDR` and exit 1. Equivalently,
  `ze0_serial.py refs --window 0xffe40010:0x10000` reports **0** loads of the
  wrong literal `0xffe41010`. The byte-order control is pinned in the same
  selftest: `sh4dis.decode(0x2FE6)` is `mov.l r14,@-r15` while the swapped
  `0xE62F` decodes to `mov #47,r6` (the M8.E1 big-endian trap).
- Scope check: ch4 (`0xffe44000`) has no register-literal pool word and ch6
  has no `+0x14` FRDR word (counted, not smoothed over).

### 4. Scope

Build-B `serial_scif.dll` executable sec0 only (`vsize 0xe322`, one exec
section); build-A/C builds, compressed sec1 IAT semantics beyond named thunks
(IAT slot `0x01f340ac` is a RETAILMSG stub), sec2/.pdata, the 47-row OAL ISR
table, runtime/L4 and vendor card data are excluded. Corpus: 16 SCIF register
pool words, 9 dispatcher call sites, 2 DMAC base literals, 10 exports, 7
`SCIF*` registry keys + HSCIF. No "all sections" claim.

### 5. Falsifier

Task falsifier: "two channels of the same driver instance use different
mechanisms with no configuration value selecting them." Also checked: an FRDR
literal attributed to a different module, an init function with 8-bit rather
than 32-bit register accesses, or `mov #N,r6` constants proving to be real
DMA channel numbers conflicting with C2a's ch1/3/7 binding. All were tested
before results; none fired.

## Interpretation

- **FACT (C-8110):** per-channel register literals and RX RAM planes (O2, O5).
- **FACT (C-8111):** the 9 call sites with their channel-index arguments (O3).
- **FACT (C-8112):** the shared HPB/general DMAC dispatcher and its register
  block (O4); all RX channels use the HPB path (index < 21).
- **FACT (C-8113):** C2a's ch1/3/7 DSAR=FRDR binding and the OAL ISR rows
  reproduce (O5, O6).
- **OBSERVED (C-8114):** the channel→mechanism→DMA-channel→VA table covers
  SCIF 1/3/7/8 as the task requires.
- **HYPOTHESIS (C-8115):** SCIF8's completion interrupt is the `0x9c0` OAL
  row; not confirmed by a live sci8 peer.
- **OBSERVED (C-8116):** registry has no mechanism selector; the falsifier
  condition does not occur (O7).
- **UNKNOWN (C-8117):** ch6 RX (kernel debug path) and deeper ISR error-flag
  branching are out of this static read.
- **FACT (C-8118):** emulator must raise the DMA completion interrupt after
  draining both planes (M8.H1 O6), not poll SCIF status (O4, O6).

## Conclusion

The firmware uses one uniform receive mechanism: an FRDR-armed, two-plane
HPB-DMAC channel per SCIF port, notified by the channel's completion
interrupt. `docs/firmware/serial-scif-rx.md` carries the full channel table
and the emulator contract; `docs/research/qemu-connectors.md` links it. The
task falsifier did not fire: no per-channel mechanism switch exists, and the
register literal (FRDR vs FTDR) is the selector. SCIF8's exact INTEVT and
ch6 RX remain open and are marked as such.
