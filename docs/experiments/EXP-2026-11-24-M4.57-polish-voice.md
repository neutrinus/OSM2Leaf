## Question

Did the `SPEECH/` language files change format between EU 2011 and EU 2014, and where does the 2011 build keep the language list that could select `PL`?

## Hypothesis

The three file kinds keep one archive framing across the years (only field values and entry sets change), and the 2011 `Speech.exe` has no `PL` name in its language table, so a stock 2011 build cannot select a 2014 `SPEECH/PL` set. Runtime decode is out of scope.

**Falsifier:** a different magic/header grammar in 2014; a `PL` name in the 2011 name table; or a printing command that returns a different field value than the one quoted below.

## Inputs

| Item | Value |

| Files | `SPEECH/SP/{GID,TTS,AGM}` on EU2011 + EU2014, `SPEECH/PL/GID` on EU2014 |
| Firmware | `Speech.exe` sec0 of EU2011 and EU2014 build A |
| Offsets / VAs | file `0x00`–`0x20` (archive header); `Speech.exe` EU2011 VA `0x00032354`, EU2014 VA `0x00036cf0` |

## Method

### 1. Sample and hash

The four images are the pinned read-only originals; `sha256sum` output is quoted verbatim in Observations. The extracted files are byte ranges of those images (7-Zip `e`, plain `SPEECH/...` paths), written only to `~/projekty/leafre-work/scratch/m4.57/`. The firmware dumps are `tools/cerom.py … extract Speech.exe -o <dir>`; the sec0 file is named by its realaddr, e.g. `Speech.exe.00011000.bin`, and its byte 0 is RVA `0x1000`.

### 2. Commands

```bash
S=~/projekty/leafre-work/scratch/m4.57
A=/home/marek/projekty/OSM2Leaf/archive/sd-images
R=/home/marek/projekty/OSM2Leaf.task-m4.57-cycle10
mkdir -p "$S/eu2011" "$S/eu2014"

sha256sum "$A/LEAF_2011-2012_QSD-309-101_navi158_eu.img" \
          "$A/LEAF_2014_EU_QSD-357-101.img" \
          "$R/archive/head256.img" "$R/archive/eu2014-256.img"

7z e "$A/LEAF_2011-2012_QSD-309-101_navi158_eu.img" \
    'SPEECH/SP/GID/SSP00000.GID' 'SPEECH/SP/TTS/TSP00000.TTS' \
    'SPEECH/SP/VR/VSP00000.AGM' -o"$S/eu2011" -y

    'SPEECH/SP/GID/SSP00000.GID' 'SPEECH/SP/TTS/TSP00000.TTS' \
    'SPEECH/SP/VR/VSP00000.AGM' 'SPEECH/PL/GID/SPL00000.GID' \
    -o"$S/eu2014" -y
sha256sum "$S"/eu2011/* "$S"/eu2014/*

python3 tools/speech_years.py --selftest
python3 tools/selftest.py --only speech_years

python3 tools/speech_years.py describe "$S/eu2011/SSP00000.GID"
python3 tools/speech_years.py describe "$S/eu2014/SSP00000.GID"
python3 tools/speech_years.py describe "$S/eu2014/SPL00000.GID"
python3 tools/speech_years.py describe "$S/eu2011/TSP00000.TTS"

python3 tools/speech_years.py compare "$S/eu2011/TSP00000.TTS" "$S/eu2014/TSP00000.TTS"
python3 tools/speech_years.py compare "$S/eu2011/VSP00000.AGM" "$S/eu2014/VSP00000.AGM"

python3 tools/cerom.py --image-start 0x200200 archive/head256.img \
    extract Speech.exe -o "$S/speech_secs"

    extract Speech.exe -o "$S/speech2014_secs"

python3 tools/speech_years.py langs  "$S/speech_secs/Speech.exe.00011000.bin" --va 0x21354 --count 10
python3 tools/speech_years.py slice "$S/speech_secs/Speech.exe.00011000.bin" 0x2139c 0x10
python3 tools/speech_years.py langs  "$S/speech2014_secs/Speech.exe.00011000.bin" --va 0x25cf0 --count 20
```

### 3. Controls

- **Positive:** `speech_years.py describe` finds the documented framing on all four real files (serial parses as 16 ASCII digits, `total` equals the file size, `count` and entry table parse), and `langs` finds 10 real names in 2011 / 20 in 2014.
- **Negative (a, mutation of a touched assertion):** a scratch copy of the 2011 Spanish GID had byte `0x20` changed from `S` to `X`; `compare` reported `DIFF entry names: ['SSP00000.GID'] -> ['XSP00000.GID']`, `DIFF first byte 0x20 (53 -> 58)`, `RESULT: different`, exit **1** (the unmutated file is not flagged). A second negative mutated the tool's own selftest expectation `header_size == 0x38` to `0x39` and the selftest failed with `selftest: 1 failure(s)`, exit **2**; restoring the file gave `selftest: 0 failure(s)`, exit **0**.
- **Negative (b, selftest):** the synthetic archive with `count=9999` is rejected with `ValueError`, and `svox_config(b"no stamp")` gives `found false`.

### 4. Scope

Offline only: three `SPEECH/SP` archives on each of EU 2011 and EU 2014 plus `SPEECH/PL/GID` on EU 2014 (7 files), the first `0x1000` bytes of each for the SVOX stamp, the uncompressed sec0 of `Speech.exe` in two firmware heads. Count: 7 files, 2 modules' sec0, 2 card images. The full prompt audio payload (GID, `TSP01000.BIN` etc.), US 2011, EU 2016, the AGM acoustic model internals, and any firmware *run* against the data are excluded (no L3/L4 harness or hardware); therefore runtime acceptance is `unknown`.

### 5. Falsifier

A different archive magic/field layout on 2014; a `PL` name in the 2011 language table; SVOX versions differing; or any quoted number not produced by the printing commands in §2. None occurred.

## Interpretation

- **FACT:** the archive framing is identical on both years and on PL 2014 (C-6320); GID is `same` framing and values differ only in serial/total/flags (C-6321, C-6323); TTS and AGM keep the framing but change entry count/sizes and names (C-6321).
- **FACT:** the SVOX voice version is unchanged (C-6322); the WAV header inside TTS is unchanged PCM 22 kHz 16-bit.
- **FACT:** the 2011 `Speech.exe` language list is the UTF-16 name table at VA `0x00032354` (10 names incl. `CF`, `US`; no `PL`); EU 2014 holds the 20-name table at VA `0x00036cf0` with `PL` (C-6325, C-6326).
- **UNKNOWN:** whether a 2011 binary would actually decode 2014 prompt bytes at runtime (no L3/L4/hardware) (C-6327). The format-level answer is `same`; the acceptance-level answer is `unknown`.
