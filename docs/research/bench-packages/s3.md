## Verify the package (outside the repo)

```bash
B=/path/to/LEAF_2011-2012_US.img     # base, read-only
S3=/path/to/us_S3.img                # the artifact
sha256sum "$B"                        # expect 53342430a1bb58d3ed6eb68c5563f079c710a400134d522e6192489b324c5383
sha256sum "$S3"                       # expect 186f2ded6263120299fc52a91db15796d8e8ce06f8886353114709be239775c1
stat -c %s "$B" "$S3"                 # expect 8057257984 twice
python3 tools/cardcheck.py --image "$S3" --hash --expect-sha256 186f2ded6263120299fc52a91db15796d8e8ce06f8886353114709be239775c1
python3 tools/imgpatch.py --check-diff --image "$S3" --reference "$B" --file MAPAL001/B18R100R.DAT --json
# expect: ok true, 0 ranges outside [106124352,106124384) and [106189824,108221440)
cmp -l "$B" "$S3" | wc -l             # expect 117 (all offsets in [107324608,107324896))
```

The last line is a prediction from the tile diff (117 bytes in the one
stream), not a recorded image measurement; if it prints anything else, the
artifact is not the M5.14 S3 card.
