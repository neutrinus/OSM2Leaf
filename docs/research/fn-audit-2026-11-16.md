# Stale `fn 0x…` citations after H52

Follow-up register for **H52** (`EXP-2026-11-16-H52-fn-citations`,
C-3490–C-3499). The post-fix audit is clean for the failure the task defines:
`python3 tools/fn_audit.py archive/head256.img` prints `START 229, INSIDE 0,
CORRECTED 25, GAP 29 (leaf 29), AMBIGUOUS 0, UNMAPPED 32`, exits 0, and
`--fix-list` is empty. What is left is not an `INSIDE` but three classes that
still *look* like a function label and must not be promoted to a reader VA
without the named task:

- `GAP` — no `.pdata` record (a leaf, an import thunk, or data);
- `UNMAPPED` — a VA outside every build-A span (another module's address);
- frozen history — append-only files H52 must not rewrite.

Fixing tasks are taken from `TODO.md`; the rule is the one AGENTS.md states:
an address becomes a `fn` label only when a `.pdata` record (M1.20/M1.23) or a
leaf proof (M1.27) backs it.
